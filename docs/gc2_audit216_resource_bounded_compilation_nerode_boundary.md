# GC-II Audit 216 — resource-bounded compilation: exact memory bound and novelty boundary

## Target
Audit 215 showed that finite endogenous rule creation can always be compiled into ordinary configuration state if representation resources are unbounded. The next question is whether the *minimum memory overhead* of any fixed-rule simulator yields a genuinely GC-specific local-to-global translator lower bound.

## Setup
Fix an external action alphabet A and observable alphabet O. A deterministic endogenous-rule system H induces, from each reachable history u in A*, a future observable response map

    rho_u : A* -> O*,

where rho_u(v) is the observable continuation produced after history u when continuation v is applied (undefined continuations may be represented by a distinguished failure symbol).

Define future equivalence

    u ~_H v  iff  rho_u(w) = rho_v(w) for every w in A*.

Let N(H) be the number of reachable equivalence classes of ~_H, possibly infinity.

A fixed-rule deterministic simulator S is required to preserve the same external interface and exact future observable behavior for every finite continuation. Let M(S) be its number of reachable internal states.

## Theorem 216.1 — exact deterministic memory bound
Every exact fixed-rule deterministic simulator S of H satisfies

    M(S) >= N(H).

If N(H) is finite, there exists an exact simulator with exactly N(H) states. Therefore

    M_min(H) = N(H),

and the minimum binary state-memory required to encode a simulator state is

    m_min(H) = ceil(log2 N(H)) bits

under ordinary fixed-length state encoding.

### Proof: lower bound
Suppose histories u and v lie in distinct ~_H classes. Then some continuation w distinguishes their future observable responses. If an exact deterministic simulator reached the same internal state after u and v, determinism would force identical future output under w, contradicting exactness. Hence distinct future-equivalence classes require distinct simulator states, so M(S) >= N(H).

### Proof: achievability
Take simulator states to be the reachable equivalence classes [u]. On action a, transition [u] to [ua]. Future equivalence is a right congruence, so this is well defined. Emit the output prescribed by H for that transition. This quotient simulator exactly realizes H. Hence M_min(H)=N(H).

## Corollary 216.2 — local-to-global memory lower bound
If an endogenous-rule construction exposes k reachable histories whose future behaviors are pairwise distinguishable by continuations, every exact fixed-rule translator/simulator needs at least k reachable states and at least ceil(log2 k) bits of state memory.

This is operational: a local history distinction that changes some possible future response cannot be globally erased by an exact deterministic translator.

## Critical novelty collision
The theorem is mathematically useful for GC-II, but it is not a new GC theorem in this unrestricted deterministic form. It is the classical future-distinguishability/minimal-realization principle: for language recognition, Myhill-Nerode identifies minimal DFA states with right-congruence classes; deterministic transducer minimization uses the analogous residual/future behavior idea.

Therefore `resource-bounded rule compilation requires log N bits` is **IMPORTED/KNOWN mechanism**, not a Paper-II breakthrough merely because N is generated by changing rulebooks.

## What survives
The exact theorem gives a clean baseline against which a genuinely GC-specific excess can be defined. Let Q(H) be the number of syntactically reachable rulebooks and N(H) the number of externally distinguishable future classes. Raw rulebook count is not invariant: different rulebooks can be future-equivalent. Conversely, physical state x and rulebook q can interact so that N(H) exceeds Q(H).

A candidate *excess compilation* quantity must therefore compare a constrained simulator class K (local, modular, bounded-interface, distributed, online, etc.) against the unconstrained Nerode quotient:

    Xi_K(H) = log2 M_min^K(H) - log2 N(H) >= 0,

when both minima are finite and K contains only exact simulators.

Xi_K removes the classical unavoidable finite-state memory baseline. It is not yet claimed novel: communication complexity, automata state complexity, distributed synthesis, branching programs, locality lower bounds, and interface theories can generate such excesses. The GC-II question is whether GC-I projection irreducibility forces Xi_K>0 for a natural K without importing that conclusion as an assumption.

## Edge and degenerate cases
- N(H)=1: zero state-information bits suffice; no positive memory lower bound.
- N(H)=infinity: no finite-state exact simulator exists.
- Unreachable histories do not contribute to N(H).
- Partial actions are handled by a failure observation or partial transition semantics; the equivalence definition must match the chosen interface.
- Approximate simulation is outside this theorem and requires an epsilon-dependent equivalence/metric.
- Nondeterministic or probabilistic simulators require a different behavioral equivalence and can invalidate the deterministic state-count statement if matching semantics are changed.
- Variable-length physical encodings need a separately specified coding model; ceil(log2 N) is the fixed-length information capacity bound.

## Status ledger
- Exact deterministic simulator state lower bound M >= N(H): **PROVED**.
- Achievability by future-equivalence quotient: **PROVED**.
- Fixed-length memory lower bound ceil(log2 N(H)): **PROVED**.
- Endogenous rulebook count Q(H) as invariant memory requirement: **FALSIFIED in general**.
- Future-equivalence/minimal deterministic realization mechanism: **IMPORTED/KNOWN**.
- Unrestricted resource-bounded endogenous-rule compilation gap as GC novelty: **FALSIFIED** (collapses to classical minimization).
- Constrained excess Xi_K forced specifically by GC-I projection irreducibility: **OPEN**.

## Consequence for Paper II
Audit 216 closes another tempting route: merely charging memory for compiling changing rules is not enough. The strongest surviving target is now a *constraint-induced excess over minimal behavioral realization*. The next audit should choose one independently motivated constraint class K—preferably locality/interface modularity because it connects to GC-I proper-projection irreducibility—and search for paired systems with identical external Nerode quotient N(H) but provably different M_min^K. A separation that is derived from GC projection structure and survives collision with communication/state-complexity theory would be materially stronger.
