# GC-II Audit 362 — Partial-observation restoration: exact criterion and prior-art boundary

## Scope
This audit attacks the surviving target from Audit 361: whether information-restricted restoration, by itself, yields a GC-II-specific theorem beyond standard partial-observation planning/diagnosis.

## Model
Let `W` be a finite set of latent operational worlds. A controller observes only `o(w)` in an observation set `O`. For each world `w`, let `R(w) subseteq A` be the set of terminal restoration actions that restore the required capability-equivalence class in that world. A policy is observation based: worlds with the same available history must receive the same next action.

For an observation fiber `C_o={w:o(w)=o}`, define its common restoration set

`K(C_o) = intersection_{w in C_o} R(w)`.

### Theorem 362.1 — one-step universal restoration criterion
There exists an observation-based one-step policy that restores every world iff

`K(C_o) != empty` for every nonempty observation fiber `C_o`.

**Proof.** Necessity: all worlds in one fiber receive the same action, so that action must belong to every `R(w)` in the fiber. Sufficiency: choose any action from each nonempty `K(C_o)`. QED.

This immediately yields the indistinguishability obstruction anticipated after Audit 361: if two observation-indistinguishable worlds require disjoint restoration-action sets, no observation-blind universally correct restoration policy exists.

## Adaptive sensing
Let `S` be a finite family of permitted sensing experiments. For a current uncertainty set `C subseteq W`, experiment `s` has outcome map `g_s:C -> Y_s`; each outcome induces a child fiber `C_{s,y}={w in C:g_s(w)=y}`. Assume sensing itself is admissible on all worlds in the current set; world-dependent admissibility can be included by deleting sensors that are not uniformly admissible on `C`.

Define recursively the solvable family `V` as the least fixed point generated by:

1. **restore:** `C in V` if `intersection_{w in C} R(w) != empty`;
2. **sense:** `C in V` if some permitted sensor `s` has at least two nonempty outcome cells and every nonempty child `C_{s,y}` lies in `V`.

### Theorem 362.2 — finite adaptive restoration criterion
A finite observation-contingent restoration tree exists for uncertainty set `C` iff `C in V`.

**Proof.** By structural induction on a successful finite tree for necessity. A leaf must use a common restoration action, hence satisfies rule 1. An internal node uses a permitted sensor and every possible child subtree succeeds, hence rule 2. Conversely, induct on the fixed-point construction rank: rule 1 gives a leaf; rule 2 attaches successful child trees below the selected sensor. QED.

### Corollary 362.3 — separating information is necessary only relative to action conflict
If `intersection_{w in C}R(w)=empty`, every successful finite policy must contain sensing that refines `C` before restoration. However, pairwise state identification is not necessary: sensing need only refine uncertainty until every terminal cell has a nonempty common restoration set.

This corrects an over-strong possible formulation of the Audit-361 target. The necessary information object is not full latent-state recovery but **decision/restoration-relevant separation**.

## Counterexample to “must identify the world”
Worlds `w1,w2,w3` have restoration sets

- `R(w1)={a}`
- `R(w2)={a,b}`
- `R(w3)={b}`.

A binary sensor separating `{w1,w2}` from `{w3}` permits universal restoration (`a` on the first cell, `b` on the second) while never distinguishing `w1` from `w2`. Thus exact world identification is not necessary.

## Edge-case audit
- Singleton uncertainty set: solvable exactly when its restoration set is nonempty.
- Empty uncertainty set: excluded as operationally vacuous; code treats it as solved by convention only internally.
- Identical restoration sets: no sensing is required.
- Empty restoration set in some world: no policy can succeed unless dynamics before the terminal action change the restoration relation; this static model correctly declares failure.
- Non-separating sensor: contributes nothing and is excluded from recursive progress to prevent cycles.
- More information cannot destroy existence when old actions/sensors remain available: the old policy can ignore it.
- Composition: independent observation fibers can be solved separately; within a fiber, success is an AND condition across all sensor outcomes.

## Prior-art collision
The mathematics above is not a new GC-II foundation. POMDP/belief-state control already makes policies depend on information states rather than hidden states, and contingent planning explicitly branches on sensing outcomes. Safe-reachability POMDP work likewise studies conditional plans under partial observation. The fixed-point/tree criterion here is an AND/OR contingent-planning formulation specialized to restoration.

Therefore the claim **“information-restricted context restoration itself is the GC-II breakthrough” is FALSIFIED**. The indistinguishability obstruction is valid but imported/known in mechanism.

The surviving GC-II-specific target must use structure not erased by this reduction. A defensible next target is a theorem tying GC-I projection irreducibility to a quantitative lower bound on the *minimum decision-relevant observation refinement* required for restoration, under an explicit restricted observation/generator language. Such a theorem must be collision-tested against sufficient statistics, Blackwell comparison/deficiency, active diagnosis, contingent planning, automata distinguishability, and communication complexity.

## Status
- One-step common-action criterion: **PROVED**.
- Finite adaptive restoration fixed-point criterion: **PROVED**.
- Indistinguishability obstruction: **PROVED / IMPORTED-KNOWN mechanism**.
- Full latent-world identification as necessary: **FALSIFIED**.
- Information-restricted restoration alone as foundational GC-II novelty: **FALSIFIED**.
- GC-I projection irreducibility => quantitative restoration-observation lower bound under restricted observation language: **OPEN / PRIORITY**.
