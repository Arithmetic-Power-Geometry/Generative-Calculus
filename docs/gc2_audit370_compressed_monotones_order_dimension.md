# GC-II Audit 370 — compressed complete monotones collapse to order dimension

Validated proof note: for a finite operational preorder, quotient operational equivalence to obtain a poset P. The minimum number d_mon(P) of arbitrary chain-valued monotones satisfying x <= y iff m_i(x) <= m_i(y) for every coordinate equals the classical Dushnik-Miller order dimension dim(P). A complete monotone vector is exactly an order embedding into a product of chains, and coordinate projections of any such embedding give a complete monotone family.

Status: equality PROVED; mechanism IMPORTED/KNOWN; arbitrary compressed monotones as a GC-II foundational breakthrough FALSIFIED. The surviving target requires GC-native monotones independently computable without first solving convertibility, invariant under conservative presentations, and constrained by a nontrivial composition/transport law.

Edge cases: nontrivial chains require one coordinate; nontrivial antichains require two; standard examples S_n have dimension n. Raw unrestricted scalar compression therefore has no universal constant bound.

Prior-art collision: order dimension is classically the least d for which a poset embeds into a product of d chains. The collision is exact, not analogous.
