# GC-II Audit 351 — Vector-budget Closure–Escape and the Pareto frontier boundary

## Scope

This audit crosses the boundary identified by Audit 350.  Audit 350 showed that finite explicit capability accounting with one additive nonnegative resource and one ordered target collapses to a classical scalar shortest-path threshold.  Here each newly grounded operational transition carries a **vector** charge in `R_+^d`, and admissibility is componentwise budget feasibility.

The graph is the finite baseline-contracted operational quotient. Baseline motion has zero vector charge. New grounded operations are explicit edges `e` with `c(e) in R_+^d`. For a finite admissible path `P`,

`c(P) = sum_{e in P} c(e)`.

For source `s` and target `t`, let

`C(s,t) = { c(P) : P is an admissible s->t path }`

and let `P*(s,t) = Min_<= C(s,t)` be its Pareto-minimal cost vectors under componentwise order.

## Theorem 351.1 — Vector-budget Closure–Escape equivalence

For every budget vector `b in R_+^d`,

` t in Cl_b(s)  <=>  exists P:s->t with c(P) <= b  <=>  exists p in P*(s,t) with p <= b.`

For a baseline-novel ordered pair the vector-budget novelty indicator is therefore

`Omega_G(s,t;b) = 1[ exists p in P*(s,t): p <= b ]`.

### Proof

The first equivalence is the definition of budgeted operational closure. For the second, any feasible path cost `x<=b` either is Pareto-minimal or dominates a Pareto-minimal path cost `p<=x`; hence `p<=b`. The reverse direction is immediate because every Pareto label is realized by an admissible path. In a finite graph with nonnegative vector charges, cycle deletion never increases any coordinate, so a Pareto-minimal cost has a simple-path representative; consequently the relevant frontier is finite.

**Status:** PROVED. The multiobjective-shortest-path/Pareto-frontier mechanism is IMPORTED/KNOWN; no novelty claim is made for that mechanism.

## Corollary 351.2 — Exact complete finite certificate

`P*(s,t)` is a complete certificate for **all** componentwise budget queries for the ordered capability `(s,t)`: two systems have identical budget-feasibility answers for every `b` iff their upward-closed feasible-budget sets coincide, equivalently iff their Pareto-minimal frontiers coincide.

**Status:** PROVED.

## Theorem 351.3 — Exact criterion for collapse back to one coordinatewise threshold vector

The feasible-budget set

`U(s,t) = {b : t in Cl_b(s)} = union_{p in P*} {b : b >= p}`

is a single principal orthant `{b:b>=p0}` **iff** `P*(s,t)` has exactly one element `p0` (excluding the unreachable case, whose feasible set is empty).

### Proof

If the frontier is `{p0}`, the formula above gives the principal orthant. Conversely, if `U` is a principal orthant generated by `p0`, its set of minimal elements is exactly `{p0}`. But the minimal elements of `U` are precisely `P*(s,t)`.

Thus Audit 350's one-threshold architecture survives vector resources exactly when the target has a unique Pareto-minimal resource requirement. Incomparable minimal requirements force a genuinely set-valued certificate.

**Status:** PROVED.

## Decisive scalar-collapse counterexample

Take two alternative `s->t` routes with cost vectors

`p=(1,0)` and `q=(0,1)`.

Then

`P*(s,t)={(1,0),(0,1)}`

and the feasible budgets form the L-shaped upper set

`{b:b1>=1} union {b:b2>=1}`.

No single componentwise threshold vector generates this set. Therefore a universal extension of Audit 350 that replaces the Pareto frontier by one vector threshold is FALSIFIED.

This does **not** claim that arbitrary encodings into one real number are impossible; such encodings can hide the entire frontier. The no-go is specifically about a semantically faithful single resource-requirement threshold under the original componentwise budget order.

## No-Free-Capability criterion

With vector charges, define `0` componentwise. Then

`0 in P*(s,t)` iff there exists a zero-total-charge admissible escape witness.

Hence, for a baseline-novel pair,

`every escape witness consumes some positive resource coordinate <=> 0 notin P*(s,t)`.

This is the direct vector analogue of Audit 350's No-Free criterion. It does not require every witness to consume the same resource coordinate.

**Status:** PROVED.

## Composition, edge cases, invariance

- `s=t`: the empty path gives vector `0`; for novelty accounting such baseline-reflexive pairs must be excluded.
- unreachable target: `P*` is empty and all finite-budget queries are false.
- zero-cost cycles: cycle deletion preserves or improves vector cost, so they do not invalidate the simple-path representative argument.
- duplicate syntactic rules grounding to the same operational edge/cost do not alter the frontier.
- state relabelling leaves the frontier invariant.
- coordinate permutation permutes the frontier and budgets equivariantly.
- adding an admissible route can only enlarge the feasible-budget upper set, but can delete old Pareto labels by domination; therefore frontier cardinality itself is not monotone under capability addition.
- serial composition adds vector costs (Minkowski sum before Pareto minimization); alternative composition unions candidate labels before Pareto minimization. This is the correct nonadditive frontier algebra.

## Exact finite stress test

`experiments/gc2_audit351_vector_budget_pareto.py` enumerates every directed three-state graph in which each of the six possible non-self edges is absent or has cost `(1,0)`, `(0,1)`, or `(1,1)`. For every ordered source-target pair it independently enumerates simple-path costs, computes the Pareto frontier, and compares frontier feasibility against direct path feasibility on every budget in `{0,1,2,3}^2`.

- exact budget-query comparisons: 393,216;
- failures: 0;
- source-target instances with frontier cardinality >1: 1,536.

## Prior-art collision boundary

The mathematical machinery here is classical multiobjective shortest-path / multicriteria path optimization: nondominated path-cost labels and Pareto frontiers are standard. The GC-II contribution of this audit is therefore a **boundary result for the program**, not a claim to have invented Pareto path labels: it identifies exactly when Audit 350's scalar complete certificate ceases to be adequate and what the exact replacement object is.

Relevant collision classes to keep active: multicriteria shortest paths, constrained shortest paths, resource-constrained reachability, vector optimization, resource theories with multiple monotones, majorization, and ordered commutative monoids.
