# GC-II Audit 335 — Compositional amplification blocks dimension-free capability accounting

## Question
Can a raw Generative Novelty Gap be bounded universally by only the increments in resources, information, action types, and rule schemas,

\[
\Omega_G \le F(\Delta R,\Delta I,\Delta A,\Delta L),
\]

when reusable rules are closed under finite composition?

## Operational construction
For each integer \(n\ge 1\), let the state space be
\(X_n=\{0,1,\ldots,n\}\).  The baseline system has only identity conversions.  The extension adds one interface action type `inc` and one reusable rule schema

\[
L_{\rm inc}:\quad i\mapsto i+1\qquad (0\le i<n).
\]

The rule consumes no charged resource and reveals no new exogenous information.  Under schema-level accounting,

\[
(\Delta R,\Delta I,\Delta A,\Delta L)=(0,0,1,1)
\]

for every \(n\).  The operational semantics permits finite sequential composition of admissible transformations.

Define the raw pair novelty gap

\[
\Omega_{\rm pair}(S_0,S_1)=
|\operatorname{Reach}(S_1)\setminus\operatorname{Reach}(S_0)|,
\]

with identity pairs included in both closures.

## Theorem 335.1 — Compositional amplification no-go
For the family above,

\[
\boxed{\Omega_{\rm pair}=\frac{n(n+1)}2}
\]

while \((\Delta R,\Delta I,\Delta A,\Delta L)=(0,0,1,1)\) is fixed.  Consequently there is no finite dimension-independent function \(F\) of only these four schema-level increments satisfying

\[
\Omega_{\rm pair}\le F(\Delta R,\Delta I,\Delta A,\Delta L)
\]

for all finite compositional operational systems.

### Proof
After adding `inc`, state \(j\) is reachable from state \(i\) exactly when \(i\le j\).  The baseline already contains the \(n+1\) identity pairs.  Therefore the newly reachable ordered pairs are exactly the strict pairs \((i,j)\) with \(0\le i<j\le n\), whose number is

\[
\binom{n+1}{2}=\frac{n(n+1)}2.
\]

If a finite universal bound existed, set \(M=F(0,0,1,1)\).  Choosing \(n\) with \(n(n+1)/2>M\) contradicts the bound. \(\square\)

## What is and is not proved
The theorem is representation-explicit.  It applies when \(\Delta A\) counts interface/action **types** and \(\Delta L\) counts reusable **rule schemas**.  If every grounding \(i\mapsto i+1\) is charged as a separate action/rule, then the increment grows with \(n\), so this particular constant-input contradiction disappears.

Likewise, a normalized gap such as

\[
\Omega_{\rm norm}=\frac{|\operatorname{Reach}(S_1)\setminus\operatorname{Reach}(S_0)|}{|X_n|(|X_n|-1)}
\]

is automatically bounded by 1 and therefore evades the unboundedness result, but only by introducing domain size through normalization.  The theorem does not rule out informative bounds that include state/domain size, grounding multiplicity, compositional depth/horizon, reuse count, or another amplification parameter.

## Corollary 335.2 — missing extensive variable
Any nontrivial universal accounting law for raw closure gain must do at least one of the following:

1. charge grounded rule/action instances rather than only schemas;
2. include a domain-size or grounding-multiplicity variable;
3. include composition/reuse depth or another amplification variable;
4. normalize the novelty quantity against an explicitly declared opportunity space; or
5. restrict the operational class so that reusable rules cannot amplify with domain size.

Thus \(\Delta R,\Delta I,\Delta A,\Delta L\) alone are not sufficient extensive coordinates under unrestricted reusable composition.

## Edge-case and invariance audit
- \(n=1\): exactly one new pair; formula gives 1.
- Identities: cancel from the difference and do not inflate novelty.
- Zero charged cost is intentional: this is a structural no-go, not a resource-pricing claim.
- Relabeling states preserves the count.
- Serial refinement of `inc` into implementation microsteps can change syntactic rule counts; hence the theorem explicitly uses the declared schema interface, consistent with the representation-sensitivity warnings from earlier GC-II audits.
- Composition is essential: without closure under repeated use, the same schema produces only \(n\) one-step ground transitions.

## Prior-art collision boundary
The mathematical amplification mechanism is ordinary graph reachability/transitive closure: reachability is the reflexive-transitive closure of the edge relation, and a path graph has a quadratic number of comparable vertex pairs.  Resource theories likewise encode convertibility by a preorder generated by allowed/free operations.  Therefore **the transitive-closure mechanism is IMPORTED/KNOWN**.  The GC-II contribution claimed here is narrower: it is a no-go constraint on the proposed four-coordinate capability-accounting architecture when reusable schemas are treated as unit increments.

## Status
- Theorem 335.1: **PROVED**.
- Quadratic formula: **PROVED** and exact-verified.
- Universal finite dimension-independent raw-pair bound using only schema-level \((\Delta R,\Delta I,\Delta A,\Delta L)\): **FALSIFIED**.
- Transitive-closure mechanism: **IMPORTED/KNOWN**.
- Bound augmented by an amplification variable: **OPEN**.
- Canonical, representation-invariant choice of amplification variable: **OPEN**.

## Next attack
Seek the weakest additional quantity \(C\) for which a non-tautological bound

\[
\Omega_G\le F(\Delta R,\Delta I,\Delta A,\Delta L,C)
\]

survives serial refinement, schema regrouping, and compositional reuse.  Candidates to falsify before adoption: number of reachable groundings, maximum useful composition depth, closure rank, and log opportunity-space size.
