# Audit 034 — Rule-gated information/action complementarity collision

## Question
Audit 033 proposed strict complementarity as the next candidate: can information and a rule/interface augmentation each be useless alone but jointly cause exact closure escape, and would that interaction constitute a GC-II breakthrough?

## Minimal exact witness
Let the hidden bit be `S in {0,1}`. The target task is exact output of `S`. Initially there is no informative executable action.

Two independent augmentations are available:

- information augmentation `i`: installs a one-bit authorization fact `K=1`, but reveals no information about `S`;
- rule/interface augmentation `a`: installs sensing action `sense`, whose execution rule is `K=1`; when executable, `sense` returns `S` exactly.

Let `D(U)` be the zero-error deficit after augmentation set `U`, with `D=1` if exact recovery of `S` is impossible and `D=0` if possible. Then

`D(empty)=1`, `D({i})=1`, `D({a})=1`, `D({i,a})=0`.

Thus neither augmentation alone changes exact capability, while their combination causes closure escape. The second-order interaction residue from Audit 029 is

`J_{i,a}=D(empty)-D({i})-D({a})+D({i,a})=-1`.

So strict complementarity exists exactly.

## Closure calculation
The initial closure contains no executable informative map. Under `i` alone, `K=1` but no sensing action exists. Under `a` alone, the sensing action exists syntactically but its precondition is false. Under `{i,a}`, `sense` is executable and maps the two hidden worlds to distinct observations. Therefore exact recovery is possible iff both augmentations are present.

This is a genuine non-additive capability effect in the declared binary deficit: both first-order gains are zero while the joint gain is one.

## Edge checks
- If `S` is degenerate, the target is already solvable and the witness vanishes.
- If `sense` is available initially, `a` is unnecessary and complementarity vanishes.
- If `K=1` initially, `i` is unnecessary and complementarity vanishes.
- If `i` itself reveals `S`, complementarity vanishes.
- If the rule is weakened so `sense` is executable without `K`, complementarity vanishes.
- Positive resource cost does not alter the logical witness, but changes which joint augmentation is budget feasible.
- With budget below the joint cost, closure escape is impossible; at or above the joint cost it is possible.
- No dimensional addition is used: `J` is defined on a dimensionless binary deficit, not on physical resource and information units.

## Prior-art collision
The mechanism is not GC-specific. Classical planning already represents actions with preconditions. Epistemic planning and Dynamic Epistemic Logic explicitly represent epistemic states together with sensing/announcement/ontic actions, and action models have preconditions determining executability. Knowledge-of-preconditions results also directly connect information/knowledge conditions to action availability. Active-sensing and contingent-planning frameworks likewise couple information acquisition and future action selection.

Therefore the implication

`strict information-action-rule complementarity => GC-II novelty`

is false.

Classification: **PROVED witness / IMPORTED-KNOWN mechanism / FALSIFIED as a standalone breakthrough criterion**.

## Consequence
Audit 033's proposed next novelty gate is too weak. A nonzero cross-axis interaction residue, even with exact closure escape and ablation-essential information/action/rule axes, can be generated by an ordinary preconditioned sensing action. Hence neither non-additivity, strict complementarity, nor multi-axis essentiality is sufficient for GC-II novelty.

A candidate Paper-II theorem must provide a quantitative conclusion that is not reproduced by compiling the system into a standard epistemic/contingent planning model with action preconditions.

## Stronger next target
Search for a *quantitative whole-envelope interaction penalty* rather than a Boolean synergy witness. Hold the same finite unlabelled transition graph and the same ordinary precondition structure fixed, and vary only task-scale-error-budget semantics. Seek families where:

1. every individual task and every permitted low-order projection has the same optimal planning/query cost;
2. the exact whole-envelope translator cost differs parametrically;
3. the difference persists after optimal policy compilation, not merely because an action is locked;
4. the lower bound requires simultaneous preservation of several task-scale-error-budget obligations;
5. removing the whole-envelope simultaneity collapses the lower bound.

This redirects the search toward an operational local-to-global translator lower bound tied to *simultaneous envelope preservation*, where GC-I projection irreducibility may contribute something not already present in ordinary gated sensing.
