# Generative Calculus II Research Program

## Working title
Generative Calculus II: The Accounting of New Capability — Closure Escape, Endogenous Inquiry, Generative Order, and Operational Novelty

## Core question
When a system acquires a new capability, was it genuinely created, or was it already latent, reachable, imported, or unlocked by new information, resources, interfaces, or rules?

## Status discipline
Every candidate result must be classified as one of: PROVED, CONDITIONAL, IMPORTED/KNOWN, NUMERICALLY SUPPORTED, FALSIFIED, OPEN.

No breakthrough claim is permitted unless the result survives proof or theorem-level derivation, adversarial counterexample search, computational stress testing where applicable, and prior-art review against reachability, viability, resource theories, Blackwell/Le Cam comparison, complexity theory, information theory, thermodynamics, marginal/contextuality theory, database decomposability, CSP width, and related simulation preorders.

## Primary mathematical objects
1. Budgeted operational closure Cl_{H,B}(E(W)).
2. Unbudgeted operational closure Cl_H(E(W)).
3. Generative Novelty Gap Omega_G(W0 -> W1).
4. Complete generative convertibility witnesses/monotones.
5. Generative Order GOrd.
6. Operational Reversibility Gap rho_G.

## Highest-value theorem targets

### T1. Closure-Escape Criterion
Develop non-tautological equivalent criteria for Omega_G(W0,W1)=0, ideally linking faithful simulation, vanishing operational deficiency, and a complete separating family of GC witnesses.

### T2. No-Free-Capability Theorem
Under fixed operational laws and complete accounting, test whether
Delta R = Delta I = Delta A = Delta L = 0 => Omega_G = 0.
The theorem must state the weakest assumptions under which it is valid.

### T3. Quantitative Capability-Accounting Bound
Seek a nontrivial bound of the form
Omega_G <= F(Delta R, Delta I, Delta A, Delta L),
allowing nonlinear interaction terms. Additivity must not be assumed without proof.

### T4. Complete Convertibility Criterion
For a structured class of worlds, seek
W0 <=_G W1 iff M_lambda(W0) >= M_lambda(W1) for all lambda,
with a finite, computable, dual, or otherwise nontrivial witness family.

### T5. Operational Local-to-Global Obstruction
Starting from projection irreducibility, test whether r_G(A,B)=k forces faithful translators to use interaction arity >=k or incur a provable resource overhead f(k), under explicit locality/composition assumptions.

### T6. Reversibility Gap
Define and test an asymptotic invariant that separates formal bijectivity from scalable operational reversibility, while collision-testing against known complexity and thermodynamic irreversibility measures.

## Exact finite-world experiments
Build enumerable finite operational worlds with finite tasks, resources, states, actions, and budgets. For each test pair compute:
- E(W0)
- Cl(E(W0))
- E(W1)
- Omega_G
- r_G / candidate GOrd
- rho_G where defined

Run exhaustive counterexample search before claiming any theorem.

## Flagship empirical application: AI capability accounting
Controlled sequence:
- base model
- + more compute
- + fine tuning
- + retrieval
- + tools
- + external memory
- + endogenous problem-frame/interface construction

Measure joint envelopes over task success/error, latency, energy/compute, memory/context, communication/tool calls, and scale. Attribute observed gains to Delta R, Delta I, Delta A, Delta L, and test for any residual Omega_G.

## Secondary applications
- autonomous systems / robotics
- communication complexity and distributed computation
- scientific discovery via endogenous question and interface construction

## Kill tests
Drop or narrow claims if:
- Omega_G reduces exactly to an established deficiency/distance;
- closure is merely standard reachability under renaming;
- GOrd yields no operational lower bound;
- rho_G duplicates a known complexity measure;
- capability accounting is only a definitional identity;
- empirical results are equally explained without GC;
- closure depends arbitrarily on modelling choices;
- no cross-domain theorem survives.

## Breakthrough threshold
A breakthrough candidate requires all four:
1. genuinely new mathematics or theorem;
2. non-reducibility to mature neighboring theory;
3. an unexpected quantitative consequence;
4. an empirical or computational discrimination test.
