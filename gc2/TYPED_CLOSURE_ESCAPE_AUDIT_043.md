# GC-II Audit 043 — Typed Closure Escape Compilation Boundary

Status date: 2026-09-10
Branch: `gc2-capability-accounting-lab`
Parent audit: 042

## Question

Can a typed closure operator on admissible generators yield a non-tautological Closure-Escape theorem or a new Generative Novelty Gap after the amortization and basis-dependence failures of Audits 041–042?

## Setup

Fix a finite physical substrate B. Let G be a finite set of installed generators. Each generator has an explicit type signature, precondition, state transition, information/interface effect, rule effect, and typed cost. Let admissible finite compositions be generated by a declared composition grammar K. Let sem(w) denote the extensional behavior of an admissible word/term w and cost(w) its accumulated typed cost under the declared composition law.

Define

Cl_B(G) = { sem(w) : w is a K-admissible finite term over G }.

For a budget vector b, define the budgeted closure

Cl_B^b(G) = { sem(w) in Cl_B(G) : cost(w) <=_B b },

where <=_B is the declared substrate-relative resource preorder. No scalarization across incompatible units is assumed.

A raw closure-escape witness is an extensional capability g such that

g notin Cl_B^b(G), but g in Cl_B^{b'}(G union Delta)

for an augmentation Delta and an explicitly stated post-augmentation budget b'.

## Theorem 043-A — Finite typed closure compiles to ordinary reachability

For every finite explicit typed-generator system above, construct a transition system whose states are pairs (x,q), where x is the physical/configuration state needed by B and q is the finite controller/typing state needed to recognize legal prefixes of K. For every applicable generator a, add a labelled transition

(x,q) --a,c(a)--> (x',q')

with exactly the original physical effect, typing update, and typed cost. If generator semantics requires finite explicit auxiliary memory, include that memory in x.

Then for every finite admissible term w:

1. w is executable in the generator system iff its labelled path exists in the compiled transition system;
2. the terminal extensional behavior is identical;
3. the complete typed cost is identical under the same composition law;
4. budget feasibility is identical.

Therefore

g in Cl_B^b(G)
iff
there exists a budget-feasible path implementing g in the compiled system.

Proof: induction on term length/tree structure. The empty term gives the identity configuration. For the induction step, admissibility of the next generator is exactly the compiled transition precondition; the transition copies the generator's state/interface/rule effect and cost update. Associative composition uses the declared law directly; if composition is non-associative, the parse/controller state stores parenthesization, so the argument still holds. QED.

Status: **PROVED**.

## Corollary 043-B — Raw Closure-Escape is not a new theorem

Adding Delta simply adds new labelled transitions/generators (or new finite controller state if Delta changes the explicit grammar). Hence

g notin Cl_B^b(G), g in Cl_B^{b'}(G union Delta)

is exactly a reachability/generation change after extending the available operation set. The statement is mathematically valid but, without an independent quantitative obstruction, is a restatement of closure/generation or reachability.

Status: **PROVED / IMPORTED-KNOWN mechanism**.

## Corollary 043-C — Membership-based Omega_G collapses to a binary restatement

Any candidate

Omega_G(g;G,Delta) = 1[g notin Cl_B(G) and g in Cl_B(G union Delta)]

contains no more information than the closure-escape predicate itself. Monotonicity of closure immediately gives Cl_B(G) subseteq Cl_B(G union Delta); therefore positive Omega_G merely records that the extension generated something previously ungenerated.

Status: **FALSIFIED as a nontrivial novelty gap**.

## Proposition 043-D — A cost lower bound is necessary but still not sufficient for novelty

Define the substrate-relative realization frontier

C_G(g) = ParetoMin { cost(w) : sem(w)=g, w admissible over G }.

A meaningful quantitative escape can compare C_G(g) with C_{G union Delta}(g), including the installation cost of Delta. However Audits 041–042 already show that such differences can be ordinary implementation, preprocessing, compilation, or amortization advantages. Thus a positive frontier separation is necessary for a quantitative capability-accounting claim but is not sufficient for GC-II novelty.

Status: **PROVED consequence of Audits 041–042; novelty OPEN only after stronger matching**.

## Edge / degeneracy / invariance checks

- Delta empty: no closure escape is possible at fixed budget and substrate.
- g already in Cl_B^b(G): Omega_G must be zero for creation; cheaper realization is resource optimization, not capability creation.
- Zero-cost Delta: permitted only when zero installation cost is justified by B; otherwise it is the free-macro artifact of Audit 041.
- Larger post-budget b': an escape may be caused solely by extra budget. Such a witness cannot be attributed to a new generator type without a matched-budget control.
- Non-associative composition: store parse state; the compilation theorem remains valid.
- Stochastic generators: finite rational kernels compile to an ordinary finite controlled stochastic process; the raw mechanism remains reachability/control, though exact quantitative decision complexity can change.
- Partial observability: explicit finite observation histories/belief states can be incorporated into the operational model; this does not by itself create a new closure principle.
- Composition: Cl_B is extensive, monotone, and idempotent when defined extensionally over all finite admissible compositions; these are ordinary closure-operator properties.
- Representation invariance: duplicating a generator name or adding semantics-identical no-ops must not change an extensional Omega_G.

## Prior-art collision assessment

The raw mathematical structure collides directly with established closure systems and algebraic generation: closure operators are extensive, monotone, and idempotent, and finite/algebraic closures are generated by finite subsets/terms. It also collides with labelled-transition reachability and simulation preorders once generator application is represented as a transition. Circuit gate-set extension and resource-theoretic operation generation are the same kind of basis-extension question at the relevant abstraction level.

Accordingly:

- Typed operational closure: **USEFUL formal language / IMPORTED-KNOWN mathematical mechanism**.
- Closure-Escape as membership change under generator extension: **PROVED but TAUTOLOGICAL/KNOWN at this abstraction level**.
- Binary membership Omega_G: **FALSIFIED as nontrivial GC-II novelty**.
- Finite explicit typed-generator compilation to reachability: **PROVED**.
- Breakthrough from a new `type` of finite explicit generator alone: **FALSIFIED**, because the type can be included in the compiled operational state/action alphabet with costs preserved.

## Consequence for Paper II

GC-II should retain budgeted operational closure as infrastructure, not sell closure membership itself as the breakthrough. A publishable theorem must concern an obstruction that is invisible to the matched ordinary compiled model, rather than a relabelling of its state/action space.

This gives a hard null principle:

**Compiled-model null principle.** If two candidate GC-II systems admit cost-preserving, reference-obligation-preserving mutual simulations of their complete finite compiled operational models, then any extensional Generative Novelty Gap must be zero.

This principle is not claimed novel; it is a filter preventing false novelty.

## Next attack — quantitative residual after complete finite compilation

The next candidate must defeat Theorem 043-A rather than evade it verbally. Seek a family indexed by n where:

1. the ordinary finite compiled systems are matched on all declared local/task projections and all horizon-indexed amortized frontiers;
2. every translator preserving the *joint* reference capability requires an auxiliary object whose minimal size/cost grows with n;
3. the lower bound is invariant under semantics-preserving state augmentation and generator renaming;
4. the lower bound cannot be reduced to ordinary automaton state complexity, communication/direct-sum, circuit/gate complexity, CSP/database width, or information recovery already isolated in earlier audits.

A concrete next object is a **compiler-invariant translator deficiency**: minimize translator cost over all cost-preserving encodings within an explicitly fixed equivalence class of substrates, then compare the resulting quotient frontiers. Before treating this as novel, collision-test it against directed deficiency/Blackwell-Le Cam, simulation distance, bisimulation metrics, resource-theoretic conversion cost, communication complexity, and universal-machine invariance.

Status: **OPEN**.
