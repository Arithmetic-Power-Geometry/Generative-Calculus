# GC-II Prior-Art Collision Audit 001

Date: 2026-09-08

## Result

**DECISIVE COLLISION / REDIRECTION REQUIRED** for two initially proposed novelty routes.

### 1. Generic complete-monotone convertibility is not a viable novelty claim

A generic statement of the form

`A <= B iff M_i(A) >= M_i(B) for all i`

is established resource-theory language. Prior work explicitly defines complete families of monotones this way. Takagi & Regula (2019) further show complete families of operational discrimination monotones for broad convex resource theories/GPT settings. Datta et al. (PRL 2023) prove that, for broad quantum resource theories containing free pure states, no finite set of monotones can completely determine all transformations.

**Status:** IMPORTED/KNOWN as a generic target. Retain only if GC-II proves a sharply restricted finite/computable representation theorem for a GC-specific structured class that evades known impossibility conditions.

### 2. Generic 'capability closure after endogenous interface synthesis' has very close 2026 prior art

Devin Bostick, *Endogenous Interface Synthesis: Capability Closure and Minimal Network Realization Across Bounded Regimes*, Zenodo v1, 2026-08-16, studies bounded evaluator networks whose interface graph can be synthesized, defines capability closure after augmentation, and derives closure via network reachability plus minimal realizing augmentations.

This is unusually close in terminology and concept to the proposed GC-II combination of endogenous interfaces + capability closure. Therefore GC-II must not claim novelty merely for defining capability closure under interface expansion or for saying new interfaces enlarge reachable capability.

**Status:** COLLISION FOUND. Generic closure/interface-expansion route is not a breakthrough candidate.

## Surviving stronger target

Refocus GC-II on a result that couples **whole task-scale-error-budget envelopes** to an operationally measurable lower bound that is not present in generic reachability/interface closure.

Promising target:

### Resource-accounted local-to-global translation obstruction

For operational worlds A and B whose all `<k`-order observable/resource projections are matched, but whose whole envelopes differ, define a translator class whose primitives have interaction arity `<k` and whose composition cannot introduce an unaccounted k-way primitive. Seek a theorem of the form

`r_G(A,B)=k  =>  no faithful (<k)-local translator exists`,

or quantitatively

`Cost_H(A -> B) >= f(k, epsilon, n)`.

The first implication must not be obtained by definition: translator locality, composition closure, ancillary resources, shared randomness, adaptivity, and approximation must be specified independently. The valuable result would be a lower bound on conversion resources/interaction order caused by globally irreducible envelope structure.

This route links the GC-I projection obstruction to convertibility and produces a potential operational consequence rather than a renamed closure concept.

## Immediate experiments

1. Exhaustively enumerate finite Boolean envelopes for m=2..5 and calculate minimum projection-distinguishing order.
2. Independently enumerate translator circuits generated by unary/pairwise primitives and test whether low-arity composition can nevertheless reproduce parity-type target envelopes through hidden state/ancillas. This is a critical falsification test.
3. Repeat with shared randomness, adaptive composition, and bounded ancilla dimensions.
4. Search for a cost lower bound rather than only an impossibility statement.
5. Collision-audit against CSP k-decomposability, database join dependencies, circuit lower bounds/parity, contextuality/marginal problems, communication complexity, and local simulation.

## Breakthrough status

No breakthrough claim. This audit eliminates two weak novelty routes and sharpens the research target toward a GC-native local-to-global operational lower bound.
