# GC-II Audit 121 — Conversion-Cone Duality Collision

## Target

Test the surviving post-Audit-120 proposal: derive resource geometry from an independently justified conversion structure, such as a cone or gauge induced by admissible resource conversions, and ask whether a representation-stable capability obstruction remains that is more than standard ordered-vector-space/resource-theory machinery.

## Setup

Let resource differences live in a finite-dimensional real vector space `V`. Let `C \subseteq V` denote the set of free/admissible resource increments. Assume for this audit that `C` is a **closed convex cone**. Define the induced preorder by

\[
x \preceq_C y \iff y-x \in C.
\]

The dual cone is

\[
C^* = \{\ell\in V^*: \ell(c)\ge 0\ \forall c\in C\}.
\]

Each `\ell\in C^*` is a linear monotone for the conversion preorder.

## Theorem 121.1 — Complete dual-monotone characterization

For a closed convex cone `C` in finite dimension,

\[
\boxed{
x \preceq_C y
\iff
\ell(x)\le \ell(y)\quad\forall \ell\in C^*.
}
\]

### Proof

If `y-x\in C`, then by definition of the dual cone,

\[
\ell(y-x)\ge 0
\]

for every `\ell\in C^*`, hence `\ell(x)\le \ell(y)`.

Conversely, if `\ell(y-x)\ge0` for every `\ell\in C^*`, then `y-x\in C^{**}`. For a closed convex cone in finite dimension, the bipolar/separation theorem gives

\[
C^{**}=C.
\]

Thus `y-x\in C`, i.e. `x\preceq_C y`.

**Status: IMPORTED/KNOWN theorem specialized to the GC-II conversion setting.** The proof is included to make the reduction explicit; it is not claimed as novel.

## Consequence 121.2 — No new convertibility criterion from the cone alone

Any proposed GC-II convertibility test depending only on membership in a fixed closed convex conversion cone has a complete description by the family of dual linear monotones `C^*`. In the polyhedral case, finitely many facet/extreme dual inequalities suffice.

Therefore a claim of a new complete capability-convertibility criterion cannot rest only on replacing coordinatewise order by an independently motivated closed convex conversion cone.

**Status: PROVED as a reduction from Theorem 121.1.**

## Gauge collision

If a convex absorbing conversion-cost set `B` is supplied, the associated Minkowski functional

\[
p_B(z)=\inf\{t>0:z\in tB\}
\]

is the standard gauge of `B`. Under suitable symmetry it becomes a norm; without symmetry it remains an asymmetric gauge. Thus introducing a physically justified convex conversion body and measuring minimum dilation needed to realize a resource difference is mathematically meaningful, but the construction itself is standard convex/gauge geometry.

**Status: IMPORTED/KNOWN construction.**

## Exact finite regression

`experiments/gc2_conversion_cone_duality_audit.py` performs an exact-integer regression in two dimensions.

It enumerates:

- all 32 primitive nonzero integer vectors in `[-3,3]^2`;
- all 480 ordered generator pairs `(u,v)` with `det(u,v)>0`, each defining a pointed 2D polyhedral cone;
- all 121 integer test points in `[-5,5]^2`;
- total membership tests: **58,080**.

For each cone, primal membership

\[
x\in \operatorname{cone}(u,v)
\]

is compared with the two extreme dual inequalities generated by

\[
n_u=(-u_y,u_x),\qquad n_v=(v_y,-v_x).
\]

Frozen result:

- interior cases: **13,320**;
- boundary cases: **2,640**;
- outside cases: **42,120**;
- primal/dual mismatches: **0 / 58,080**.

Result file: `gc2/results/AUDIT_121_conversion_cone_duality.json`.

This computation is a regression/check of the finite polyhedral specialization, not evidence of novelty.

## Prior-art collision gate

The core mathematics is established convex and vector optimization:

1. Orders induced by closed convex cones and scalarization by positive/dual functionals are standard in vector optimization.
2. Dual cones provide separation and dual characterizations of efficient/dominance structures.
3. Convex vector optimization explicitly studies primal/dual images, cone ordering, scalarizations, and geometric duality.
4. Minkowski functionals/gauges are standard ways to derive a cost geometry from a convex absorbing set.
5. Resource theories use allowed transformations and monotones to characterize or bound convertibility; a fixed convex conversion cone is therefore within an established ordered-resource template.

Representative collision sources checked during this audit include Eichfelder (SIAM J. Optim.) on arbitrary cone-induced partial orders and scalarization; Qiu (SIAM J. Optim.) on dual-cone characterizations/scalarization; Löhne and collaborators' convex vector-optimization geometric-duality line; and general geometric duality for ordered vector spaces/cones.

## Decisive result

The post-Audit-120 rescue attempt

\[
\text{"derive a physically justified conversion cone/gauge, then obtain a new GC-II obstruction"}
\]

fails **as a standalone novelty mechanism** for closed convex conversion structures.

The reason is structural rather than empirical:

\[
\boxed{
\text{closed convex conversion cone}
\Longrightarrow
\text{complete dual-monotone family}
}
\]

and a convex conversion body/gauge is already standard convex analysis.

This does **not** show that every physically meaningful conversion system is convex, memoryless, or path-independent.

## Next surviving target

The next defensible gate is **path dependence / nonintegrability**, not a richer static cone. Seek two conversion systems with the same instantaneous feasible conversion cone and the same endpoint resource differences, but different achievable closed conversion cycles because admissibility depends on path/history. Define a cycle residual only if it survives:

- augmentation of state by finite memory/history variables;
- thermodynamic work-cycle / hysteresis formulations;
- nonholonomic control and geometric phase/holonomy;
- shortest-path/min-cost-flow and dynamic programming reductions;
- resource-theory catalysis and state-dependent conversion rates.

If the residual is merely holonomy, hysteresis, nonholonomic reachability, or ordinary path-dependent optimal control under another name, reject it.

No breakthrough claim is made in this audit.
