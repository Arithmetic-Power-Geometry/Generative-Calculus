# GC-II Audit 048 — Interaction-Obstruction Collision

Status date: 2026-09-10
Branch: `gc2-capability-accounting-lab`
Parent audit: 047

## Question

Can the mixed intervention response proposed after Audit 047 become a GC-II breakthrough invariant merely by requiring representation invariance, zero interaction on independent products, evaluator-drift safety, and an exact finite-world lower-bound witness?

## Setup

For a conserved reference decision problem d, typed budget b, and horizon h, let V_S be minimized reference loss. For two typed interventions delta_1 and delta_2 define

M_S(delta_1,delta_2)
 = V_{S+delta_1+delta_2}
 - V_{S+delta_1}
 - V_{S+delta_2}
 + V_S.

The four terms have identical loss units. No heterogeneous R/I/A/L coordinates are added. Negative M denotes complementary loss reduction under this sign convention; positive M denotes redundancy/antagonism.

## Exact finite-world counterexample

Take one conserved binary obligation q with loss 1 on failure and 0 on success. There is one target action a, but it is executable only when two independent prerequisites p and q are simultaneously present. Initially neither prerequisite is present.

- baseline S: target infeasible, V_S=1;
- delta_1 installs only prerequisite p: target remains infeasible, V_{S+delta_1}=1;
- delta_2 installs only prerequisite q: target remains infeasible, V_{S+delta_2}=1;
- delta_1+delta_2 installs both: target becomes feasible, V_{S+delta_1+delta_2}=0.

Therefore

M_S(delta_1,delta_2)=0-1-1+1=-1.

This is an exact, deterministic, finite witness with no evaluator drift, no stochastic estimation, and no representation dependence once the four extensional systems are fixed.

Yet the mechanism is only threshold complementarity: neither input alone crosses the feasibility threshold and the pair does. Hence a nonzero mixed response, even one surviving compilation and evaluator-drift checks, does not establish a new generative mechanism.

Status: **PROVED counterexample; interaction response as standalone novelty mechanism FALSIFIED**.

## Why the stronger filters do not rescue novelty

### 1. Vanishing on independent products

If delta_1 acts only on component S_1, delta_2 only on independent S_2, and the reference loss is additively separable,

V_{S_1 x S_2}(delta_1,delta_2)=V_1(delta_1)+V_2(delta_2),

then the mixed finite difference is exactly zero by cancellation. This is a desirable sanity check but is the standard separability property of mixed differences; it is not GC-specific.

Status: **PROVED algebraic cancellation; IMPORTED/KNOWN mechanism**.

### 2. Compiler invariance

If a compiler preserves each of the four extensional reference values exactly, it preserves M exactly because M is their signed linear combination. Thus compiler invariance follows automatically from value preservation and supplies no additional obstruction.

Status: **PROVED; methodological property, not novelty**.

### 3. Evaluator-drift safety

Using one conserved evaluator E* across all four systems blocks the false-positive mechanism identified in Audit 038. The finite witness above still has M=-1. Thus evaluator-drift safety is necessary bookkeeping but does not distinguish GC interaction from ordinary complementarity.

Status: **PROVED by witness**.

### 4. Exact lower-bound witnesses

The threshold example already supplies |M|=1, the maximum possible magnitude for this particular {0,1}-loss construction. Exact finite witnesses therefore do not rescue novelty: standard complementarity can satisfy the same evidentiary standard.

Status: **PROVED by construction**.

## Higher-order extension

For k interventions define the Boolean-lattice/Mobius mixed difference

M^{(k)}_S(delta_1,...,delta_k)
 = sum_{J subseteq [k]} (-1)^{k-|J|} V_{S+sum_{j in J} delta_j}.

A k-way AND prerequisite system has V=1 for every proper subset and V=0 only when all k prerequisites are installed. Its highest-order mixed term is nonzero. Thus arbitrarily high interaction order can be generated by an ordinary conjunction gate/threshold constraint.

This kills a tempting escape route: "nonzero interaction of unbounded order" is not sufficient for GC-II novelty. Boolean functions, cooperative-game interaction indices, discrete derivatives, CSP constraints, circuits, and database joins already generate such higher-order dependence.

Status: **PROVED finite family; novelty interpretation FALSIFIED**.

## Resource-theoretic collision

Catalysis and activation already show that transformations impossible under one resource configuration can become possible in the presence of another resource while the assisting resource may be returned or otherwise constrained. Therefore a qualitative "jointly possible, separately impossible" signature is not unique to GC-II.

Status: **IMPORTED/KNOWN collision**.

## Communication/direct-sum collision

Joint realization cost can differ from the sum of separate realization costs. Communication complexity explicitly studies direct-sum and amortized phenomena, including settings in which simultaneous computation has a smaller per-instance cost than isolated computation. Therefore nonadditive joint operational cost is also not a GC-specific signature.

Status: **IMPORTED/KNOWN collision**.

## Dimensional, edge, and composition checks

- M is dimensionally valid only because all four V terms use the same conserved loss scale.
- If either intervention is null in all four relevant contexts, M=0.
- M can change sign; no universal positivity is available without super/submodularity assumptions.
- Rescaling the loss by alpha rescales M by alpha, so no universal magnitude theorem is possible without loss normalization.
- Under additive independent products and disjoint interventions, M=0.
- Under shared constraints, bottlenecks, thresholds, common fixed costs, information fusion, or catalytic resources, M may be nonzero without any new primitive capability law.
- Higher-order mixed differences are representation-safe only with an extensionally conserved intervention semantics; splitting one intervention into syntactic sub-interventions can otherwise manufacture interaction order.

## Consequence for Omega_G

No candidate of the form

Omega_G = f({mixed finite differences of V})

is a GC-II breakthrough merely because it is nonzero, high-order, compiler-invariant, evaluator-safe, or zero on independent products. All of these signatures occur in established complementarity/coupling/activation constructions.

The interaction-obstruction route proposed in Audit 047 is therefore **FALSIFIED as a standalone novelty mechanism**.

## Stronger surviving target

The next target must not ask whether interventions interact. It must ask whether there is an **irreducible local-to-global implementation burden after every proper sub-intervention response has been matched**.

For a family indexed by n, seek paired systems S_n,T_n such that:

1. every proper local intervention/projection up to order n-1 has matched conserved response behavior;
2. the global obligation differs;
3. any admissible translator that reconstructs the global behavior from the complete proper-local data must pay a provable growing typed cost L_n;
4. L_n is invariant up to an explicitly stated equivalence under semantics/cost-preserving compilation;
5. the lower bound is not merely input-size, parity/query complexity, communication complexity, CSP width, database join/decomposability width, contextuality/marginal inconsistency, circuit complexity, or proof complexity in disguise.

This directly reconnects Paper II to GC-I proper-projection irreducibility while imposing the operational translator-cost requirement missing from the earlier projection result.

Candidate quantity (no novelty claimed):

Lambda_n = inf { c(T) : T reconstructs the conserved global obligation from the declared family of proper-local interfaces }.

The decisive next step is to construct an exact finite family and prove a superconstant lower bound for Lambda_n, then attempt explicit reductions to parity/query, multiparty communication, CSP/database width, marginal/contextuality, and circuit lower-bound frameworks. If every witness reduces to one of those theories, this route must also be rejected.

Status: **OPEN**.

## Final classification

- Pairwise mixed response M: **VALID / IMPORTED-KNOWN interaction diagnostic**.
- Nonzero M as Omega_G: **FALSIFIED**.
- Zero-on-independent-products requirement: **PROVED sanity condition / not novel**.
- Compiler invariance of M under exact value preservation: **PROVED / automatic**.
- Evaluator-safe nonzero interaction: **PROVED possible / not novel**.
- Unbounded interaction order as novelty: **FALSIFIED by conjunction family**.
- Jointly-possible/separately-impossible signature: **IMPORTED/KNOWN activation/complementarity collision**.
- Irreducible proper-local-to-global translator lower bound after matching all proper local responses: **OPEN; next severe target**.
