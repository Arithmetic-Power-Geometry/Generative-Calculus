# GC-II Audit 169 — Closure-Witness Spectrum Yoneda Collision

Status date: 2026-09-16
Branch scope: `gc2-capability-accounting-lab` only. GC-I/main unchanged.

## Objective

Attack the Audit-168 surviving object `C_G`: restrict capability coordinates to observables generated by budgeted operational closure itself, rather than arbitrary lookup-table monotones, and test whether minimum witness-cost / threshold-closure coordinates yield a genuinely GC-specific separating spectrum.

## Finite budgeted operational model

Fix a finite operational state set `X`. Every admissible transformation edge `e:x->y` has nonnegative cost `c(e)` in a chosen scalar budget unit. (Vector budgets are treated separately below.) Define the minimum closure-witness cost

`D(x,z) = inf { sum_e c(e) : admissible path x -> z }`,

with `D(x,z)=+infinity` if no admissible path exists.

The associated threshold closure witness is

`W_{z,b}(x) = 1[D(x,z) <= b]`.

Both are generated from the actual admissible transformations and budget convention; neither is an arbitrary monotone lookup table.

## Theorem 1 — closure-witness cost is a directed Lawvere metric

For all `x,y,z`:

1. `D(x,x)=0` (empty admissible path);
2. `D(x,z) <= D(x,y)+D(y,z)` by path concatenation;
3. symmetry and identity-of-indiscernibles need not hold;
4. `+infinity` correctly represents unreachable targets.

Thus `(X,D)` is exactly an extended directed Lawvere metric (a category enriched over the cost quantale `[0,+infinity]` with reversed order and addition).

**Status: PROVED / IMPORTED-KNOWN STRUCTURE.**

## Theorem 2 — threshold witnesses contain exactly the same scalar closure information as D

If all real thresholds are admitted,

`D(x,z) = inf { b >= 0 : W_{z,b}(x)=1 }`.

Conversely `W_{z,b}(x)=1` iff `D(x,z)<=b`. Therefore the complete threshold-witness spectrum and the minimum-cost-to-target spectrum are information-equivalent.

For finite graphs with finitely many finite simple-path costs below any fixed cap, it suffices to use the attained critical thresholds rather than all real numbers.

**Status: PROVED.**

## Theorem 3 — full target-indexed closure spectrum is representable/Yoneda data

The map

`Y:x |-> D(x,-)`

is the covariant distance-profile representation of the enriched category. It is not a new GC-specific kind of dual observable: it is the representable/Yoneda-style embedding supplied by enriched category theory.

Moreover, the full family reconstructs the original directed distance immediately because its coordinate at target `z` is exactly `D(x,z)`. In particular, for every pair `(x,y)`, the operational conversion cost `D(x,y)` is already one coordinate of `Y(x)`.

Hence a capability spectrum consisting of *all minimum closure-witness costs to all targets* is complete, operationally generated, and non-lookup-table — but its completeness is classical enriched-category structure.

**Status: PROVED / IMPORTED-KNOWN MECHANISM.**

## Corollary — zero-threshold witnesses recover reachability

For zero-cost/free reachability, or after replacing each finite admissible edge by zero cost when only feasibility matters,

`x >= z  iff  W_{z,0}(x)=1`.

Thus the target-indexed closure indicators reduce to principal reachability sets, the same finite-preorder representation already encountered in Audit 167. Adding quantitative minimum costs enriches the preorder to a directed metric, but does not by itself create a new generative invariant.

## Decisive novelty boundary

Audit 168 required `C_G` to be:

- operationally generated;
- smaller than arbitrary monotones;
- capable of separating meaningful systems.

Minimum witness-cost coordinates satisfy those desiderata in natural finite weighted systems. Nevertheless, their *full target-indexed spectrum* collides with Lawvere enrichment/Yoneda representation. Therefore merely restricting arbitrary monotones to `D(x,z)` or threshold versions `1[D(x,z)<=b]` does **not** clear the GC-II novelty gate.

This is stronger than saying the spectrum resembles resource cost: its canonical mathematical representation is already known.

## Edge and degenerate cases

- `x=z`: `D(x,x)=0`; every nonnegative threshold witness is true.
- unreachable `z`: `D(x,z)=+infinity`; every finite threshold witness is false.
- zero-cost cycles: permitted; they produce zero directed distance between distinct states and therefore a pseudometric-like operational quotient, not a contradiction.
- parallel edges: only the least-cost path matters to `D`; internal multiplicity is intentionally forgotten. Any proposed invariant depending on multiplicity is not identifiable from this closure-cost spectrum.
- negative edge costs: excluded. Allowing them destroys the standard nonnegative cost quantale and can create negative-cycle pathologies; such a model requires a different algebra and cannot inherit this theorem unchanged.
- composition: path concatenation gives the triangle inequality. Independent-system product costs depend on the declared composition rule (sum, max, vector, etc.); additivity must not be assumed without that rule.

## Vector-budget boundary

For a vector resource cost `r(e) in R_+^k`, replacing scalar `D` by the Pareto set of nondominated path costs is more faithful than choosing an arbitrary scalarization. But this immediately moves the object toward enrichment over an ordered commutative monoid/quantale and multi-resource reachability. No novelty claim is made for vector-valued closure profiles. A GC-II result would have to establish structure beyond generic quantale-enriched reachability or multiobjective shortest paths.

## Consequence for Omega_G

Neither

`Omega_G(x,z)=D(x,z)`

nor the full threshold profile

`Omega_G(x)={W_{z,b}(x)}_{z,b}`

is defensible as a new foundational quantity. The first is operational conversion distance; the second is its threshold encoding.

A residual candidate must therefore use information *not recoverable from endpoint minimum conversion costs alone* while remaining operationally invariant. One precise next test is a **witness-geometry residual**: compare systems having identical all-pairs minimum closure-cost matrix `D` but different constrained witness structure (for example, disjointness, bottleneck concurrency, mandatory-resource co-use, or number/topology of admissible minimal witnesses), then ask which such distinctions survive operational equivalence and which collapse to path categories, flow/cut theory, Petri nets, provenance semirings, or enriched-category refinements.

Crucially, path multiplicity alone is not enough: if no allowed operational experiment can distinguish two implementations with the same `D`, Audit 164 makes any multiplicity-dependent quantity unidentifiable. The next construction must expose the residual through an explicitly admissible operational query.

## Paper-II consequence

Audit 169 closes the most natural implementation of Audit 168's restricted `C_G`: minimum closure costs and their threshold witnesses are operationally meaningful but mathematically classical. Do not claim `bdim_G` novelty when `C_G` consists solely of target-indexed minimum conversion costs or their thresholds. The next exact finite search should deliberately construct pairs with identical all-pairs `D` but distinguishable admissible witness geometry, and then test whether the distinguishing experiment is genuinely outside standard path/flow/provenance/resource-theory machinery.
