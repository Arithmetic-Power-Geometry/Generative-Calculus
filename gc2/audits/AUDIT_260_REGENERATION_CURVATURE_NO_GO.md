# GC-II Audit 260 — Regeneration curvature no-go

Status: **PROVED / decisive falsification of a tempting simplification**

## Setup
For a fixed finite nonnegative-cost operational system, start state x, semantic capability universe U, and state annotation S(z) subseteq U, define

C_x(T) = inf { c(pi) : pi takes x to z and T subseteq S(z) },

with C_x(empty)=0 and +infinity when T is unreachable. On finite-valued instances C_x is a monotone set function: A subseteq B implies C_x(A) <= C_x(B).

A natural attempted rescue after Audit 259 is to impose a generic curvature law on C_x, especially submodularity (substitutes/diminishing returns) or supermodularity (complements/increasing returns), and then use the resulting low-order structure for capability accounting. Neither law follows from the GC-II operational axioms.

## Theorem 260.1 — No universal submodularity
For every K>0 there is a finite nonnegative-cost operational system on U={a,b} with

C(empty)=C({a})=C({b})=0,  C({a,b})=K.

Construction: x has zero-cost edges to states carrying {a} and {b}, and a K-cost edge to a state carrying {a,b}; no cheaper state carries both.

For A={a}, B={b}, submodularity would require

C(A)+C(B) >= C(A union B)+C(A intersection B),

hence 0 >= K, contradiction.

Therefore regeneration cost is not universally submodular.

## Theorem 260.2 — No universal supermodularity
For every K>0 there is a finite nonnegative-cost operational system with

C(empty)=0, C({a})=C({b})=C({a,b})=K.

Construction: x has one K-cost edge to a state carrying {a,b}, and no cheaper nonempty-capability state.

Supermodularity would require

C(A)+C(B) <= C(A union B)+C(A intersection B),

hence 2K <= K, contradiction.

Therefore regeneration cost is not universally supermodular.

## Corollary 260.3 — Interaction sign is operational, not fixed
For finite-valued C on two atoms, the Boolean-lattice Mobius coefficient

m({a,b}) = C({a,b}) - C({a}) - C({b}) + C(empty)

is +K in the complement construction and -K in the substitute construction. Thus the same GC-II axioms permit positive or negative second-order interaction. Monotonicity alone fixes neither interaction sign nor curvature.

## Corollary 260.4 — k-additive/Mobius truncation is an assumption, not a consequence
For finite U and finite-valued C, Mobius inversion gives the exact identity

C(T) = sum_{A subseteq T} m(A).

This is an **IMPORTED/KNOWN** representation of set functions, not a GC-II novelty claim. Audit 259 already proves that arbitrarily high-order interactions can be indispensable. Consequently, setting m(A)=0 above a fixed order k is a structural model assumption that requires generator/target locality; it cannot be derived from generic budgeted operational closure.

## Dimensional/domain audit
- C and every Mobius coefficient m have units of operational cost.
- K>0 may carry any chosen cost unit; rescaling all edge costs by lambda>0 rescales C and m by lambda and preserves both counterexamples.
- C(empty)=0 follows from the zero-length path.
- Infinite values are excluded from Mobius arithmetic; the no-go already holds entirely in finite-valued systems.
- Both examples obey nonnegative edge costs and finite state/action sets.
- Monotonicity under requirement inclusion is preserved in both examples.

## Composition/invariance audit
Renaming states or capability atoms leaves the inequalities unchanged. Positive cost rescaling preserves violation sign. Independent product composition does not repair a violated factor: fixing the other factor's requirement at empty reproduces the original restriction.

## Prior-art collision boundary
Mobius transforms, capacities, submodular/supermodular set functions, and k-additive capacities are established mathematics. This audit claims only the GC-II **boundary result**: the generic regeneration profile generated by finite nonnegative-cost operational reachability is monotone but need be neither submodular nor supermodular, so curvature-based accounting requires additional structural hypotheses.

Relevant established literature includes Grabisch, Marichal & Roubens (2000), *Equivalent representations of set functions*, Mathematics of Operations Research 25(2):157–178, and the broader submodular/valued-CSP literature.
