# GC-II Audit 040 — Minimal Verifier-Congruence Boundary

## Purpose

Audit 039 proposed quotienting all verifier-relevant state by future operational equivalence before attributing any residual state growth to Generative Calculus. This audit tests whether the resulting minimal quotient can itself support a GC-II breakthrough.

## Status summary

- Minimal future-verifier congruence: **PROVED** to be a well-defined right congruence in the deterministic finite setting below.
- Minimality of its quotient among deterministic exact reference-obligation recognizers: **PROVED** by the standard distinguishable-continuation argument.
- Minimal verifier-quotient growth as a standalone GC-II novelty mechanism: **FALSIFIED**.
- Proof mechanism and state-complexity interpretation: **IMPORTED/KNOWN**, essentially Myhill–Nerode/minimal automaton theory after encoding reference outcomes as an output language.
- GC-specific residual after exact minimization: **OPEN**.

## 1. Deterministic finite reference semantics

Let `H` be the set of reachable finite histories generated by an admissible finite action alphabet `A`. Let a conserved reference evaluator assign to every completed history an outcome vector

\[
E^*(h)\in O,
\]

where `O` is a finite set encoding all declared reference-obligation outcomes (for example a Boolean vector over tasks, scales, and error-budget tests).

For histories `h,h'`, define

\[
h\equiv_* h'
\quad\Longleftrightarrow\quad
E^*(hu)=E^*(h'u)
\text{ for every admissible common continuation }u.
\]

If admissibility itself depends on history, include an explicit failure/out-of-domain outcome in `O`; then every action word has a defined continuation semantics and the comparison remains total.

## 2. Theorem 040.1 — future-verifier equivalence is a right congruence

The relation `equiv_*` is an equivalence relation. Moreover,

\[
h\equiv_*h'\Longrightarrow ha\equiv_*h'a
\]

for every action `a`.

### Proof

Reflexivity, symmetry and transitivity follow pointwise from equality of the reference outcome for every continuation. If `h equiv_* h'`, then for every continuation `u`, the word `au` is itself a continuation, hence

\[
E^*(hau)=E^*(h'au).
\]

Therefore `ha equiv_* h'a`. QED.

## 3. Theorem 040.2 — exact minimality

Let

\[
Q_*=H/\!\equiv_*
\]

be the quotient by future reference-obligation equivalence. Any deterministic exact machine whose current internal state is sufficient to reproduce `E^*(hu)` for every future continuation `u` must have at least `|Q_*|` reachable states.

### Proof

Take two histories in distinct equivalence classes. By definition there exists a continuation `u` for which their reference outcomes differ. If an exact deterministic recognizer mapped both histories to the same internal state, applying the same continuation `u` would produce the same future internal trajectory and hence the same output, contradicting exactness. Thus distinct equivalence classes require distinct machine states. The quotient machine itself is sufficient because the right-congruence property makes the successor class under each action well-defined. Hence `|Q_*|` is exact. QED.

### Information corollary

Any fixed-length binary encoding of an exact sufficient deterministic state requires at least

\[
\boxed{\lceil\log_2 |Q_*|\rceil\text{ bits}}
\]

in the worst case, and this bound is attainable up to the ceiling by indexing quotient states.

This is a representation-independent lower bound only after the operational semantics and exact deterministic model have been fixed.

## 4. Why this closes the proposed novelty route

The quotient above is not a new GC-specific mathematical object. Encode each possible reference outcome (or each component of the finite outcome vector) as an accepting/output condition over action histories. Two histories are equivalent precisely when no future suffix distinguishes their required reference behavior. This is the classical future-context equivalence underlying Myhill–Nerode theory and deterministic automaton minimization.

Therefore a family with exponentially growing `|Q_*|` can certainly prove a large minimal sufficient-state requirement, but that fact alone is an automata/state-complexity result. Calling the states `generative obligations`, `certificates`, or `whole-envelope states` does not create a new theorem.

Hence

\[
\boxed{\text{growth of the minimal future-verifier quotient}\not\Rightarrow\text{GC-II novelty}.}
\]

The proposed post-Audit-039 route is therefore **FALSIFIED as a standalone breakthrough criterion**.

## 5. Domain and dimensional checks

`|Q_*|` is a cardinality. `log_2 |Q_*|` is measured in bits only after choosing exact binary state encoding. Neither quantity may be added directly to energy, time, money, action count, or other resource coordinates without a declared conversion/cost model.

The quotient depends on:

1. the admissible continuation language;
2. the conserved reference evaluator;
3. exact versus approximate equivalence;
4. deterministic versus randomized realization;
5. whether budgets/resources are included in continuation state.

If remaining budget affects future outcomes, it must be included in the semantic state before quotienting. Otherwise histories with different future feasibility can be incorrectly merged.

## 6. Edge and degenerate cases

- If all histories have identical future reference behavior, `|Q_*|=1`.
- If every reachable history is distinguishable by some continuation, no nontrivial minimization is possible.
- If the quotient index is infinite, no finite deterministic exact sufficient-state machine exists; this is again the familiar infinite-index obstruction, not automatically GC novelty.
- If only bounded-horizon continuations are tested, the resulting quotient can be strictly coarser and may hide long-horizon distinctions.
- Approximate error tolerance requires a metric/pseudometric analogue; ordinary equivalence no longer suffices. Such approximate-state minimization overlaps bisimulation metrics, predictive-state compression, rate-distortion and approximate automata.
- Randomized machines require a declared success/error semantics. The deterministic exact lower bound cannot simply be reused.
- Parallel composition can make quotient cardinality submultiplicative, multiplicative, or smaller because components can share sufficient state. No universal additive law follows.

## 7. Consequence for Omega_G

Do not define `Omega_G = log |Q_*|` or a difference of such quantities as the GC-II novelty gap. That would primarily rename minimal state complexity.

A defensible `Omega_G` must survive quotient minimization but also measure something not already captured by the minimal recognizer of the complete declared future behavior.

This is a severe constraint: if two finite deterministic systems have identical complete continuation-to-reference-outcome maps, then they are operationally indistinguishable for the declared semantics. No nonzero GC capability gap can be claimed between them without adding a new observable primitive.

This yields a useful **identity-of-operational-content principle**:

\[
\boxed{\Phi_X=\Phi_Y\Longrightarrow \Omega_G(X,Y)=0}
\]

for any extensional GC-II novelty gap, where `Phi` is the complete admissible-continuation to conserved-reference-outcome map including declared costs/budgets. This is **PROVED as a consistency requirement from extensionality**, not claimed as novel mathematics.

## 8. Consequence for Closure-Escape and No-Free-Capability

Once the complete continuation semantics are fixed, closure escape is an ordinary property of that semantic map. Minimal-state growth can lower-bound memory/information required to implement the map, but it does not by itself yield a new Closure-Escape theorem.

Likewise, a No-Free-Capability theorem cannot charge merely for an increase in quotient-state count unless the augmentation is required to physically or informationally realize those states under a declared implementation model. Otherwise the cardinality is descriptive complexity rather than consumed resource.

## 9. Stronger surviving target

The next target must move from **state cardinality** to **resource-bounded realization of a fixed extensional capability map**.

Construct pairs/families with the same conserved reference semantics at the extensional level but different admissible implementation primitives `R/I/A/L`, and ask for the exact Pareto cost of realizing the same continuation-to-outcome map. The candidate GC object should be an implementation frontier rather than a state count:

\[
\mathcal C(\Phi)=\operatorname{ParetoMin}\{(R,I,A,L):\text{an admissible realization implements }\Phi\}.
\]

The scientifically hard question is whether changing the primitive realization basis creates a quantitative obstruction or conversion law that is not already standard circuit complexity, communication complexity, query complexity, control realization, resource theory, or automata implementation cost.

A future breakthrough candidate must therefore exhibit a residual after all of the following are held fixed or quotiented away:

- complete extensional future behavior;
- evaluator and evidence semantics;
- representational state redundancy;
- finite provenance/certificate encodings;
- ordinary transition reachability;
- known implementation-complexity measures.

## 10. Next exact experiment

For small finite deterministic transducers:

1. enumerate reachable histories up to stabilization;
2. compute the exact future-outcome partition by partition refinement;
3. verify the quotient against brute-force distinguishing continuations;
4. enumerate restricted realization bases (allowed observations, actions, rule gates, and vector costs);
5. compute Pareto-minimal realizations of the same quotient transducer;
6. search for basis changes whose Pareto separation is not explained by state count alone;
7. collision-test every surviving quantity against circuit, communication, query, control-realization and resource-theoretic complexity.

No result from step 6 should be called GC-specific until step 7 fails to absorb it.

## 11. Paper-II status

No breakthrough is claimed. Audit 040 decisively removes minimal verifier-congruence growth as a standalone novelty route. The minimization itself is scientifically necessary because it eliminates representational artifacts, but its exact deterministic finite form is classical future-context/minimal-automaton mathematics.

The surviving GC-II program is narrower and stronger: capability accounting must concern the Pareto cost of **realizing conserved extensional capability under explicitly restricted operational primitives**, not merely the number of states needed to remember future distinctions.
