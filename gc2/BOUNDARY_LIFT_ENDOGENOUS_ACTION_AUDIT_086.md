# GC-II Audit 086 — Endogenous Action-Space Boundary Lift Compiles to Augmented-State Dynamics

## Scope

## Target inherited from Audit 085
Test the first candidate Minimal Boundary-Lift Separation mechanism: endogenous creation/modification of the admissible interface/action set.

## Result
**FALSIFIED as a standalone GC-II novelty source under explicit finite/computable action-generation rules.** If the current admissible action/interface set and the rule that changes it are continuation-relevant, they can be included in the operational state. The apparently changing action boundary then becomes ordinary fixed-grammar dynamics on an augmented state space.

### Definition — endogenous-interface system
Let a system have physical/informational state `x in X`, currently enabled action set `A in F`, ordinary actions `a in A`, and meta-actions `m in M` that can modify the enabled set. Let

\[
T(x,A,u)=(x',A'), \qquad u\in U,
\]

where `U` is a fixed universe containing ordinary and meta-actions, and admissibility is represented by a predicate

\[
E(x,A,u)\in\{0,1\}.
\]

A meta-action may create, delete, parameterize, expose, hide, or replace an interface/action by changing `A`.

### Theorem 1 — Action-boundary compilation theorem (PROVED)
Assume:
1. `U` is fixed for the model (finite or computably presented);
2. all continuation-relevant effects of action/interface modification are represented by `(x,A)`;
3. admissibility and transition rules are explicit;
4. costs/errors generated by an action are functions of the augmented state, action, and transition.

Then the endogenous-interface system is behaviorally equivalent to an ordinary transition system on augmented state

\[
Z=X\times\mathcal F,
\]

with fixed action alphabet `U`, state-dependent admissibility predicate `E`, and transition

\[
\widetilde T((x,A),u)=T(x,A,u).
\]

For every finite admissible history in the endogenous description there is exactly the same history of physical states, enabled interfaces, outcomes, typed costs, and errors in the augmented-state description, and conversely.

**Proof.** Map each endogenous configuration to `z=(x,A)`. At each step, the same predicate `E` selects exactly the same enabled actions. Applying `u` invokes the same transition `T`, hence produces the same successor `(x',A')` and the same declared cost/error. Induction on history length gives equality of reachable histories and therefore equality of any task–scale–error–budget closure computed from those histories. QED.

### Corollary 1 — Boundary motion is not sufficient (PROVED)
Merely allowing the action/interface set to change does not escape fixed-boundary operational theory. It changes which component is called "state". A GC novelty claim therefore cannot be based only on

\[
A_t\neq A_{t+1}.
\]

### Corollary 2 — apparent escape diagnoses omitted state or an open universe (PROVED/CONDITIONAL)
If two histories have the same declared `(x,A)` but different future admissible capabilities, the declared state is incomplete. If no fixed/computable universe `U` can contain the actions that may later be generated, assumption 1 fails; this is a genuinely stronger open-world case, but novelty is not established by failure of compilation alone.

### Typed-budget preservation
Let each transition carry

\[
c(z,u,z')=(\Delta R,\Delta I,\Delta A,\Delta L)\in\mathbb R_{\ge0}^4
\]

or any explicitly declared nonadditive history functional. Since the compilation preserves the full history, it preserves additive ledgers, Pareto frontiers, and arbitrary history-dependent cost functionals. Therefore typed accounting does not invalidate Theorem 1.

## Stress audit
- **No meta-actions:** reduces immediately to the ordinary fixed-interface model.
- **Action addition:** encoded by changing the `A` component.
- **Action deletion:** same.
- **Tool parameterization/macros:** encode generated definitions in the continuation-relevant state; state size may grow, but representational growth is not a new operational law.
- **Random action generation:** include random transition kernels; the correspondence is distributional.
- **Persistent external tool/server state:** include it in `x` if it affects continuation.
- **Hidden catalyst/memory:** omission creates a false boundary lift; sufficient-state completion restores the theorem.
- **Unbounded generated action descriptions:** allowed when computably presented; `Z` may be countably infinite.
- **Noncomputable/open-world action source:** compilation into a computably presented fixed `U` may fail. This is outside the theorem and remains OPEN.
- **Composition:** product/composed systems retain the construction by augmenting with the joint enabled-interface state.
- **Invariance:** renaming actions or interface identifiers leaves reachable closure invariant under the induced isomorphism.

## Prior-art collision
The action-space-evolution idea has a direct 2026 collision: Posadas and Vega, *Thinking Is Not Enough: The B* Expansion Technique for Enhancing Autonomous LLM Agents* (Expert Systems, published 18 June 2026), explicitly models an LLM agent that iteratively constructs new actions and expands `B* = B union A*`. Modified-action MDPs and standard state-dependent admissibility/action-precondition formalisms are additional nearby structures. Thus dynamic action/interface sets cannot be claimed as a uniquely GC-II concept.

The stronger compilation observation is also structurally standard: when a variable affects future transition/admissibility, augmenting the Markov/operational state with that variable restores an ordinary state-transition representation. The GC contribution would have to lie beyond this encoding, not in the encoding itself.

Candidate lift (1) from Audit 085 is eliminated in its ordinary finite/computable form.

A surviving target must violate at least one compilation assumption in a scientifically controlled way and then produce a quantitative consequence not reducible to open-world planning, program synthesis, grammar induction, computability, or ordinary augmented-state reachability.

The next ordered candidate is therefore:

**Coupled-index nonseparability problem (OPEN).** Determine whether task–scale–error–typed-budget closure contains a provably irreducible interaction when all single-index and fixed-joint-boundary comparison theories are factored out. The burden is to exhibit a precise nonseparability law or lower bound, not merely a multivariate constraint.

A candidate interaction residual should be tested against inclusion–exclusion/Mobius interaction, multiobjective optimization, rate-distortion/resource tradeoff regions, information bottleneck, multi-parameter complexity, and ordinary nonseparable utility/cost functions before any GC novelty claim.
