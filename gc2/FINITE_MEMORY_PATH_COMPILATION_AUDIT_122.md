# GC-II Audit 122 — Finite-Memory Path Dependence Compiles into State

## Question

Can the post-Audit-121 path-dependent/nonintegrable conversion route produce a standalone GC-II invariant when the conversion rule has finite internal memory?

## Setup

Let `X` be a physical state space, `M` a finite memory space, `A` an action set, and let the operational evolution be

\[
(x_{t+1},m_{t+1})=T(x_t,m_t,a_t),
\]

with a typed increment/cost

\[
g(x_t,m_t,a_t,x_{t+1},m_{t+1}).
\]

If only `x` is observed, two paths that begin and end at the same physical state can have different future conversion possibilities or different accumulated typed increments because they end with different memory values. This is path dependence at the physical projection.

## Theorem — Finite-Memory Path Compilation

**Status: PROVED.**

For every finite-memory path-dependent conversion system `(X,M,A,T,g)`, define the compiled state space

\[
Z=X\times M.
\]

Use exactly the same transition rule and increment map on `Z`. Then for every initial configuration, every finite action word, every horizon, and every additive path functional obtained from `g`, the original system and the compiled system have identical trajectories in `(x,m)` and identical accumulated typed increments.

### Proof

Induct on word length. At length zero the augmented states agree. Assume the states agree after `t` actions. Applying the same next action to the same pair `(x_t,m_t)` invokes the same deterministic (or, with kernels, the same conditional stochastic) transition rule and the same typed increment. Therefore the next augmented states and accumulated increments agree. The result follows for every finite word.

No special geometry is required.

## Consequence

A nonzero closed-cycle residual seen only after projecting away finite memory is not an intrinsic escape from ordinary operational state semantics. It is produced by an incomplete state description.

Thus a candidate such as

\[
\Omega_G(\gamma)=\text{net capability/resource change around a physically closed path}
\]

is **FALSIFIED AS STANDALONE NOVELTY** whenever the path dependence is generated by finite reifiable memory and the GC operational state is allowed to include that memory.

This does not say that all path-dependent systems are trivial. It says that GC-II cannot claim novelty merely from finite-memory history dependence or projected hysteresis.

## Exact finite kill test

`experiments/gc2_finite_memory_path_compilation_audit.py` exhaustively enumerates a small deterministic class with:

- one projected physical state;
- two internal memory states;
- two actions;
- all 16 Boolean memory-update tables;
- all 16 `{−1,+1}` typed-increment tables;
- all action words through the fixed test horizon 6.

Frozen result:

- systems: **256**;
- sequence checks: **16,384**;
- systems exhibiting nontrivial path dependence at the physical projection: **196**;
- original-vs-compiled mismatches: **0**.

The 196 witnesses confirm that projected path dependence is genuinely present in most members of this toy class; the zero mismatch confirms that promoting finite memory into state removes any semantic discrepancy exactly.

## Prior-art collision gate

The mechanism collides with established state-augmentation methods for non-Markovian objectives and history-dependent decision problems. Finite-history or automaton memory is routinely converted into Markov state by product construction. Recent work also studies canonical/minimal augmented states for history-dependent preferences rather than treating augmentation itself as a new operational principle.

Nonholonomic/geometric-phase systems do exhibit physically meaningful closed-path effects, but those effects are already part of the full configuration/control state-space geometry. Therefore geometric phase or holonomy cannot be claimed as GC-II novelty without an additional theorem tying it specifically to GC capability accounting and surviving reduction to established control geometry.

## Next kill gate

The surviving question is not whether path dependence exists. It is whether the **minimal operational memory required to make capability evolution Markov/sufficient**, optimized over admissible representations, yields a GC-specific invariant that is not already one of:

- minimal automaton/state complexity;
- predictive-state dimension/rank;
- statistical sufficient-state construction;
- computational mechanics causal-state complexity;
- information/communication memory lower bounds;
- POMDP belief-state complexity;
- geometric-phase/holonomy structure.

Until that collision gate is passed, no breakthrough claim is warranted.
