# GC-II Audit 073 — Boundary-Stable Novelty Defect No-Go

## Scope
Branch-only Paper-II audit. GC-I `main` is frozen.

## Candidate inherited from Audit 072
After completing ordinary conversion theory, seek systems S,T with S equiv_* T but a positive typed novelty defect after changing a physical accounting boundary J.

## Result
**Status: FALSIFIED as stated; a boundary-change dichotomy is PROVED under explicit assumptions.**

### Definition 073.1 — Closed typed ledger
Fix an operational model M and a closed accounting universe U. Every protocol p has a typed total ledger

c_U(p) = (R_U(p), I_U(p), A_U(p), L_U(p))

with coordinates kept typed; no addition across dimensions is assumed. A boundary B partitions each coordinate into internal and crossing/external contributions according to a declared bookkeeping rule. Let C_B(S) denote the complete task-scale-error-budget closure of S under the free operations declared by M.

### Definition 073.2 — Pure accounting-boundary morphism
A map J:B -> B' is *pure* when it changes only attribution/bookkeeping: it does not change physical histories, admissible transformations, task/error semantics, interfaces, available side information, catalysts, randomness, or the total closed-universe ledger c_U(p). It may reclassify a cost from external to internal or vice versa.

### Theorem 073.1 — Pure-boundary invariance / covariance
Let S equiv_* T mean mutual convertibility in the completed operational theory under the same M. If J is a pure accounting-boundary morphism, then J cannot create a representation-independent physical capability distinction between S and T. More precisely, the protocol sets and total typed ledgers are unchanged, and every boundary-resolved frontier at B' is the image of the same underlying protocol/ledger set under the B' bookkeeping projection. Hence any claimed positive BSND that appears solely because a cost coordinate is reassigned across the boundary is an accounting-coordinate effect, not a new physical capability.

**Proof.** A pure J leaves the set P(S) of physically admissible protocol histories invariant and leaves c_U:P(S)->K invariant. It only replaces one attribution map pi_B by pi_B'. Since S equiv_* T in the completed theory, their task-relevant protocol closures are mutually simulable under M. Applying a common bookkeeping projection to unchanged histories cannot break physical mutual convertibility. If a numerical boundary-resolved quantity changes, the change is induced by pi_B -> pi_B', while the closed-universe physical ledger and reachable task/error set remain unchanged. Therefore no boundary-stable positive physical novelty defect can be generated by pure reclassification. QED.

### Theorem 073.2 — Operational-boundary change is model change
If J changes which transformations, information, interfaces, reservoirs, agents, catalysts, randomness, or side resources are physically accessible, then J is not pure. It maps M to a different operational model M'. A positive difference

C_B^M(S) != C_B'^{M'}(S)

can then be physically real, but it is a relative comparison between two resource/constraint theories. It does not contradict S equiv_* T, because equiv_* was defined relative to M and need not be preserved by changing M.

**Proof.** Operational equivalence is indexed by the allowed transformation set and accounting assumptions. Changing these changes the preorder itself. Thus the apparent post-boundary defect is either (i) bookkeeping under fixed M, covered by Theorem 073.1, or (ii) a comparison across M and M'. QED.

### Corollary 073.3 — Boundary-Stable Novelty Defect dichotomy
Under a closed ledger and explicit model:

1. pure boundary change => no new physical capability distinction; only covariant re-accounting is possible;
2. capability-changing boundary change => the operational theory has changed.

Therefore the Audit-072 BSND cannot serve as a standalone GC-II breakthrough invariant without additional structure that is neither mere reclassification nor an undeclared change of free operations.

## Edge-case audit
- **Open universe:** theorem does not apply until omitted reservoirs/channels are represented; apparent creation may be unaccounted flow.
- **Boundary-dependent measurement error:** if task/error semantics change, J is operational, not pure.
- **Side information crosses boundary:** operational model changes unless the information was already represented in the closed ledger.
- **Catalyst moved across boundary:** if accessibility changes, model changes; if only ownership label changes, pure re-accounting.
- **Nonlinear typed costs:** allowed. Proof uses no additivity, convexity, or scalarization.
- **Composition:** preserved for pure J because physical histories/composition law are unchanged.
- **Degenerate zero-cost resources:** do not affect theorem.
- **Infinite frontiers:** set-theoretic argument still applies if the attribution maps are defined.
- **Representation changes:** absorbed by equiv_*; a bookkeeping label cannot resurrect a distinction already quotiented out.

## Prior-art collision interpretation
The no-go is consistent with thermodynamic/system-boundary bookkeeping: moving a boundary changes which flows are internal/external while closed-system conservation remains a statement about the total ledger. It is also consistent with resource theories, where changing the free-operation set changes the resource theory and its conversion preorder. Therefore 'accounting boundary' by itself should not be marketed as a new source of capability.

## Consequence for Paper II
Do not pursue BSND as currently defined. The useful result is instead the **Accounting-Boundary Dichotomy**: any valid capability-accounting theorem must state whether a boundary transformation is a covariant re-accounting map or an operational model morphism. Mixing the two can manufacture false novelty gaps.

## New surviving target — Minimal Operational Model Extension Cost
The next candidate should explicitly embrace model change rather than hide it. Let M subset M' denote an extension that adds specified admissible primitives. Define

Omega_ext(q; S, M -> M') = Min_Pareto { Delta : there exists an extension E of M with typed installation/availability cost Delta and q in C^{E}_{scale,error,budget}(S) }.

This is only **OPEN**. It becomes trivial if arbitrary primitives may be installed at declared zero cost. To have content, admissible model extensions must themselves be generated from a fixed meta-operational grammar with charged physical interfaces. The immediate kill tests are resource-theory transformations between theories, simulation/interpretation of operational theories, compiler/ISA extension, oracle/advice complexity, mechanism/environment augmentation, and reachability with actuator/sensor placement.
