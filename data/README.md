# Data

`mlperf_power_public_subset.csv` contains the small public-data subset used in the manuscript's non-toy validation. Values were transcribed from the cleaned inference-datacenter data distributed with the public MLPerf Power HPCA-2025 repository. The file is included for deterministic reproduction; it is not claimed as an original dataset.

Source study: Arya Tschand et al., **MLPerf Power: Benchmarking the Energy Efficiency of Machine Learning Systems from Microwatts to Megawatts for Sustainable AI**, HPCA 2025, DOI 10.1109/HPCA61900.2025.00092.
