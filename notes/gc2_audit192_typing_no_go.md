# GC-II Audit 192 — Typing Alone Does Not Restrict Monotone Closure

## Status

- **PROVED:** Typed-Witness Universality Theorem below.
- **FALSIFIED:** The hypothesis that a weakest unconstrained typed compositional-witness axiom, by itself, forces a strict forbidden pattern or inequality on finite monotone acquisition-to-capability maps.
- **IMPORTED/KNOWN collision:** Once stronger token-consumption/production semantics are imposed, the resulting models overlap Petri-net / coloured-Petri-net reachability; if one instead imposes extensive, idempotent implication closure, the model overlaps classical closure systems / pure Horn implication systems.
- **OPEN:** Find the weakest *non-vacuous* structural axiom on generative composition that is independently motivated by GC operational semantics and excludes at least one monotone map without simply restating a known Petri-net, Horn, CSP, database, automata, or resource-theory restriction.

## Setup

Let `E` be a finite set of acquired evidence/resource/interface tokens and `X` a finite set of capabilities. Let

`F : 2^E -> 2^X`

be monotone: `S subseteq T` implies `F(S) subseteq F(T)`.

A weak typed compositional-witness system consists of:

1. one primitive token type `tau_e` for every `e in E`;
2. capability output types `kappa_x` for every `x in X`;
3. typed witness actions whose input interface is a finite product of token types and whose output is a capability type;
4. an action may fire only when all required input token types are present;
5. acquired tokens are persistent/read-only for this weak model, so using a witness does not consume them.

This is deliberately the weakest natural typing discipline: type-correctness constrains which inputs a witness may inspect, but places no algebraic restriction on which finite typed input signatures may exist.

## Theorem — Typed-Witness Universality

For every finite monotone `F : 2^E -> 2^X`, there exists a finite weak typed compositional-witness system whose capability closure is exactly `F` at every acquired-token set.

### Construction

For each capability `x`, define its minimal enablers

`M_x = { T subseteq E : x in F(T), and x notin F(U) for every proper U subset T }`.

For every `T in M_x`, introduce one typed witness

`w_(x,T) : product_{e in T} tau_e -> kappa_x`.

The empty product is allowed when `x in F(emptyset)`.

Given acquired set `S`, declare `x` reachable iff at least one `w_(x,T)` is type-enabled, equivalently iff some `T in M_x` satisfies `T subseteq S`.

### Proof

If `x` is reachable at `S`, some minimal enabler `T in M_x` obeys `T subseteq S`. Since `x in F(T)` and `F` is monotone, `x in F(S)`.

Conversely, if `x in F(S)`, finiteness of `E` guarantees an inclusion-minimal `T subseteq S` with `x in F(T)`. Then `T in M_x`, so `w_(x,T)` is type-enabled at `S`, hence `x` is reachable.

Therefore the typed operational closure equals `F(S)` for every `S subseteq E`. QED.

## Consequence — No forbidden pattern from unconstrained typing

Because *every* finite monotone map is realizable, no property stronger than monotonicity can be derived from this typing axiom alone. In particular, typing alone cannot universally imply submodularity, supermodularity, convexity, exchange, bounded interaction order, local-to-global reconstructibility, unique factorization, smooth frontier deformation, or any nontrivial Closure-Escape inequality.

The theorem also shows why simply assigning unique or arbitrarily refined types cannot rescue the program: refinement can encode the witness relation rather than constrain it.

## Edge and degeneration checks

- `E = emptyset`: constant capability sets are represented by nullary witnesses.
- `X = emptyset`: closure is empty for every acquisition state.
- Capabilities already present at baseline: represented by empty-input witnesses.
- Capability never attainable: has no witness.
- Duplicate witnesses: semantically redundant and do not change closure.
- Type renaming: closure invariant under bijective renaming of token/capability types.
- Composition: independent enabled witnesses can be executed in either order because inputs are persistent; no extra capability appears unless a typed witness explicitly produces it.
- Monotonicity: adding persistent input tokens cannot disable an existing witness.

## Prior-art boundary

This result is a no-go lemma, not a novelty claim about typed transition systems. Stronger semantics immediately enter established territories. Petri nets use typed/placed tokens with transitions enabled by required inputs and explicit token consumption/production; coloured Petri nets add token data/types and guards. If GC instead requires an extensive, idempotent monotone closure generated by implications, classical closure-system / pure-Horn machinery applies. Therefore the next GC-II axiom must be justified operationally and collision-tested before treating any resulting representation theorem as novel.

## Breakthrough gate after Audit 192

Do **not** search over arbitrary type labels. Search over structural laws that cannot encode an arbitrary monotone table for free. Candidate gates to falsify next:

1. bounded arity plus a *fixed finite reusable type algebra* independent of the target table;
2. compositional factorization in which witness semantics must be generated from a fixed primitive transformation basis rather than introduced per minimal enabler;
3. resource-conserving or resource-monotone typed composition with explicit state transitions;
4. uniform-family constraints where the description of the type/action algebra is sublinear relative to the represented closure table;
5. translator lower bounds for compiling a global capability relation into such a restricted local typed basis.

The scientific target is a strict representability boundary plus a quantitative compilation/translator lower bound, not typing by itself.
