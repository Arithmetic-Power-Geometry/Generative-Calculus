# GC-II Audit 354 — decisive prior-art collision: antichain resource accounting

## Status

**IMPORTED/KNOWN / DECISIVE NOVELTY BOUNDARY.**

This audit does not change GC-I and does not retract the correctness of Audits 350–353. It narrows what Paper II may legitimately claim as new.

## Collision

Audits 351–353 establish, for a requested operational capability, that vector-valued nonnegative resource requirements are exactly represented by the Pareto-minimal antichain of feasible requirements, while scalar weighted sums are generally incomplete.

That architecture is not GC-II-specific. Monotone Co-Design / Monotone Design Problems already model functionality and resources as partially ordered sets and map a functionality request to an antichain of minimal resources. In that literature, upper-set feasibility and minimal-resource antichains are dual descriptions of the same monotone feasibility relation, and series/parallel/feedback composition is part of the framework.

Accordingly, the following cannot be advertised as a Paper-II foundational novelty without a stronger distinguishing theorem:

1. functionality-to-minimal-resource antichain maps;
2. upper-set budget feasibility generated by a Pareto antichain;
3. antichain composition as such;
4. the general observation that scalarization can discard nondominated alternatives.

The shortest-path specialization in Audits 350–353 remains useful as a verified reduction/boundary result, but the general vector-resource antichain viewpoint is **IMPORTED/KNOWN**.

## Exact reduction

Let a GC-II capability query be a functionality element `f`, let the resource poset be `(R, <=)`, and let `Impl(f)` denote admissible implementations/witnesses with resource map `r(i) in R`. Define

`H(f) = Min_{<=} { r(i) : i in Impl(f) }`.

Then budget `b` permits `f` exactly when

`exists p in H(f) with p <= b`.

This is precisely the minimal-resource antichain / upper-closure semantics used by monotone co-design. Thus renaming `H(f)` as a GC-II capability frontier does not create a new mathematical object.

## Consequence for the breakthrough program

The surviving target must exploit structure absent from this imported reduction. Candidate distinguishing axes are:

- information-dependent admissibility in which acquiring the information needed to select/authorize an implementation itself changes admissibility or resource state;
- endogenous rule/interface generation rather than a fixed implementation relation;
- cross-capability shared budgets where independent per-function antichains are not compositional certificates;
- a genuine operational local-to-global translator lower bound inherited from GC-I projection irreducibility;
- a reversibility-gap invariant not reducible to ordinary resource-poset asymmetry;
- a theorem coupling novelty/closure escape to semantic increments `(Delta R, Delta I, Delta A, Delta L)` under explicit assumptions.

The next audit should therefore leave the fixed-functionality/fixed-resource-poset antichain regime unless it is proving a sharp impossibility boundary.
