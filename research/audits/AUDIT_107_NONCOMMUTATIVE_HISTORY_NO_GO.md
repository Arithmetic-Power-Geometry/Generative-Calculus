# GC-II Audit 107 — Noncommutative history obstruction no-go

Status: **PROVED (algebraic reduction); IMPORTED/KNOWN mechanism; FALSIFIES the next generic breakthrough route**

Branch scope: `gc2-capability-accounting-lab` only. GC-I/main is not modified.

## Question
After Audit 106 rules out a novel endpoint-exact additive balance, can GC-II obtain a breakthrough merely by replacing scalar/vector edge increments with an order-sensitive, noncommutative path quantity?

## Setup
Let `G=(V,E)` be a directed operational graph. Assign each edge `e` an element `h(e)` of a monoid `M`, not assumed commutative. For a path

`P=e_1...e_k`,

define the ordered history product

`H(P)=h(e_1) h(e_2) ... h(e_k)`.

For a closed path `C` based at `v`, `H(C)` is a loop/history witness. If `M` is a group and vertex gauges `g(v)` change edge labels by

`h'(u->v)=g(u)^(-1) h(u->v) g(v)`,

then a closed-loop product transforms by conjugation:

`H'(C)=g(v)^(-1) H(C) g(v)`.

Hence only conjugacy-invariant functions of loop products are gauge-independent scalar witnesses without additional structure.

## Theorem 107.1 — Ordered-history factorization
Any edge-local history quantity satisfying

1. identity on the empty path, and
2. `H(PQ)=H(P)H(Q)` whenever paths concatenate,

is exactly a monoid-valued path representation: it factors through the free path category (or, after forgetting endpoints, through the generated transition monoid).

### Proof
The path category is freely generated by the directed edges subject only to legal concatenation. Conditions (1)–(2) uniquely extend the edge assignment `e -> h(e)` to a functorial/path-product assignment. Therefore order sensitivity alone adds no structure beyond a representation of path composition in a monoid.

## Corollary 107.2 — Noncommutativity no-go
Replacing additive increments in Audit 106 by noncommuting matrices/operators/group elements does not by itself yield a new GC-II invariant. The resulting witness is a standard ordered product/transition-monoid object. If loop products are retained, the construction is history/holonomy-like; if only endpoint behavior is retained, it reduces to the induced transformation semantics.

Therefore a candidate `Omega_G` built only as a norm, trace, spectral quantity, conjugacy class, rank, word length, or other scalarization of `H(P)` requires an independent theorem connecting that quantity to capability creation. The algebraic construction itself is not the breakthrough.

## Proposition 107.3 — Commutator detects order but not new capability
For two composable generators `a,b` represented in a group, the commutator

`K(a,b)=h(a)h(b)h(a)^(-1)h(b)^(-1)`

is the identity whenever the two represented operations commute, and can be nonidentity otherwise. Thus it detects an order/composition obstruction missed by an abelianized additive accounting. But this is exactly ordinary noncommutative algebra: nonzero/nonidentity commutator is not, without a separately derived operational consequence, a GC-II capability law.

## Edge and degenerate cases
- If `M` is commutative, ordering disappears and the construction collapses toward ordinary commutative path weights.
- If every edge maps to the identity, all path and loop witnesses are trivial.
- If two distinct paths induce the same element of `M`, this witness cannot distinguish them.
- Enlarging `M` to the free monoid on edge labels can remember the entire word/history, but then the witness is merely a lossless encoding of history and gives no compression or new theorem.
- Quotienting `M` can create useful invariants, but every claimed capability consequence must be proved after the quotient and collision-tested against known automata/semigroup/process theory.
- For group-valued gauges, raw loop products are base/gauge dependent up to conjugacy; a scalar claim must respect this or explicitly fix a gauge.

## Prior-art collision gate
Weighted automata already assign algebraic weights to transitions and compose path weights using semiring multiplication. Transition monoids/semigroups encode ordered compositions of automaton transformations. History-dependent automata explicitly retain resources/history acquired in past transitions. Krohn–Rhodes theory decomposes finite transformation semigroups into cascades of simpler reset and permutation components. Consequently, order sensitivity, noncommuting transition products, or loop/holonomy-style witnesses are not sufficient novelty conditions.

## Scientific consequence
The post-Audit-106 route is narrowed again. A surviving GC-II candidate must do more than retain path order. It must derive, from independently fixed operational semantics, a quotient-invariant higher-order quantity and prove a quantitative capability-accounting consequence that is **not reconstructible from the full transition monoid/path semantics itself** or from standard weighted/history-dependent automata, semigroup decomposition, process theory, or ordinary computation/communication lower bounds.

A useful kill test is therefore:

> If the proposed obstruction is computable solely from the complete labelled transition system plus an edge-local monoid assignment, classify it first as an imported path-algebra/process invariant. GC-II novelty must lie in an additional independently justified capability theorem, not in the ordered product.
