# GC-II Audit 106 — Boundary-balance cycle no-go

Status: **PROVED (finite exact theorem); IMPORTED/KNOWN mechanism; FALSIFIES a generic breakthrough route**

Branch scope: `gc2-capability-accounting-lab` only. GC-I/main is not modified.

## Question
Can an independently fixed microscopic transition system yield a new quotient-invariant scalar capability balance merely by assigning a local capability increment to each transition and demanding path-independent accounting?

## Setup
Let `G=(V,E)` be a finite directed operational graph. Each edge `e:u->v` has an independently fixed local scalar increment `w(e)` (the same argument applies coordinatewise to typed vectors). For a directed walk `P=e_1...e_k`, define

`W(P)=sum_i w(e_i)`.

Call the accounting **endpoint-exact** when every two directed walks with the same start and end have the same accumulated increment. Equivalently, on each strongly connected component, every directed closed walk has zero total increment.

## Theorem 106.1 — Cycle/potential equivalence
On a strongly connected finite directed graph, the following are equivalent:

1. Every directed closed walk has total increment zero.
2. `W(P)` depends only on the endpoints of `P`.
3. There exists a vertex potential `Phi:V->R` such that for every edge `u->v`,

   `w(u->v)=Phi(v)-Phi(u)`.

### Proof
(3)->(2): telescoping gives `W(P)=Phi(v)-Phi(u)`.

(2)->(1): a closed walk has identical start/end, hence its value equals that of the empty walk, zero.

(1)->(3): fix a root `r`. For each `v`, choose any directed path `P_{r,v}` and set `Phi(v)=W(P_{r,v})`. Strong connectivity supplies a directed return path from `v` to `r`; zero closed-walk sums imply any two `r->v` paths have equal weight. For an edge `u->v`, append it to an `r->u` path. Path independence gives `Phi(v)=Phi(u)+w(u->v)`, proving the claim.

For a general directed graph the statement applies componentwise; cross-component accounting requires explicit boundary/reference choices and is not generated by path independence alone.

## Corollary 106.2 — Gauge no-go
If a proposed scalar GC-II capability balance is (i) local-edge additive, (ii) exact/path-independent, and (iii) determined solely by fixed microscopic transitions, then inside every strongly connected operational region it is a potential difference. Relabeling the potential or calling it `Omega_G` does not create a new conservation law.

If some directed cycle has nonzero total increment, exact endpoint accounting fails. The residual is then path/history dependent and must be modeled as such; it cannot simultaneously be claimed as an endpoint state invariant.

## Typed/nonadditive warning
For typed `R,I,A,L` increments, the theorem applies coordinatewise whenever each coordinate composes additively. For max/peak, bottleneck, multiplicative, or other declared composition laws, no additive conclusion is asserted: each law requires its own algebraic/cocycle analysis. Applying a nonlinear scalar `F` after an ordinary vector potential does not by itself escape the reduction.

## Edge/degenerate cases
- Zero increments: `Phi` may be constant; theorem remains valid.
- Self-loop: endpoint-exactness forces its increment to zero.
- Parallel edges: endpoint-exactness forces equal increments between the same ordered endpoints when return paths exist.
- Disconnected/SCC DAG: potentials have independent additive gauges per SCC; inter-SCC edges can carry reference-dependent offsets.
- Negative increments: allowed; no positivity assumption is used.
- Quotienting states: a potential descends to a quotient only if it is constant on equivalence classes (up to the chosen gauge). This is an additional requirement, not automatic.
- Composition: concatenation is exactly the path-sum operation used in the proof.

## Prior-art collision
This theorem is the standard graph-potential / conservative-edge-weight / exact-1-cocycle mechanism. Therefore an endpoint-exact additive boundary balance is not, by itself, a GC-II breakthrough. Closure systems and implicational bases also already formalize generated consequences; antimatroids/convex geometries formalize accessible closure-like growth. Generic resource monotones likewise already encode conversion order. These neighboring theories must remain collision gates.

## Scientific consequence
The surviving target cannot be merely

`Delta capability = boundary flux`

with an additive local flux and path-independent endpoint value. To survive this audit, a candidate must derive from fixed operational dynamics a genuinely history-sensitive, noncommutative, higher-order, or otherwise non-potential obstruction, and then prove a quantitative capability consequence that does not reduce to standard path costs, cocycles/potentials, resource monotones, information processing, reachability/viability, thermodynamics, or ordinary computation/communication complexity.
